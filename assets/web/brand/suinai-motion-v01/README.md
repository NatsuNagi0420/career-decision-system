# 穗奈原画动作小样 v01

日期：2026-10-19。

预览入口：`http://127.0.0.1:5174/?preview=suinai-motion`。

这是使用已收到的真实穗奈部件制作的 Canvas 二维动作试验，供判断现有素材的眨眼和陪伴效果。不是 Cubism 网格绑定，不包含 `.cmo3`、`.moc3` 或新增闭眼/张嘴原画。

输入：`D:\Project\career-decision-system\docs\品牌形象\Live2D原画\04-拆层交接\穗奈v2_脸底实际修补小样_v01.zip`。

导出器优先使用前次独立审查目录中的 Pillow 依赖，存在系统 Pillow 时也可运行；不修改前后端包依赖。源 ZIP 哈希不符会停止，不能直接把另一个版本覆盖进本版本。

## 已实现与限制

- 自动/手动眨眼：压合真实眼白、虹膜、睫毛部件；闭眼线条来自睫毛压合，不是新增手绘眼睑。
- 自然呼吸与眨眼；待机、招手、倾听、思考、回应、完成六个本地动作及台词示意。
- 2026-10-19 v03：复用 handwear-l/r 实际双臂图层，以连续三角网格弯曲肘与腕，固定肩缝；不新增手形。
- 完整双手/上半身/面部近景、动作进度与开合滑条、暂停续播、重播、连播、三种背景。
- 遵循系统减少动态偏好；素材缺失会报错并允许重试。
- 头部有独立侧倾和点头，脸与头发始终同步运动，避免现有脸底里固定头发与独立刘海发生位移；这没有修复脸底本身。
- 不制作说话口型，不作头发独立运动，不声称已有真实转头、物理效果、语音同步或 Agent 状态接入。

第一版重点是让用户实际看效果。二维压合效果是否足够自然，仍需目视确认，浏览器测试通过不能代替美术评价。
