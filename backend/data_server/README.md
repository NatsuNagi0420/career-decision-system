# Backend Data Server

Put backend-managed static assets here.

- Images: `backend/data_server/images/`
- Public image path: `/data-server/images/{filename}`
- URL resolver API: `/api/v1/assets/images/{filename}`

Only validated image files are public. The backend must not expose the whole `data_server` directory as a broad static resource root.

Frontend clients should request asset URLs from backend APIs instead of composing asset URLs locally. Returned URLs are generated by the backend from the current request context.
