# Windows 内测发行

用户双击 Setup.exe，选择安装路径并创建桌面快捷方式。双击快捷方式后，本机 Agent 在后台启动，随后打开默认浏览器中的 WebUI；不启动 Vite，也不需要用户安装 Node.js 或执行 npm。

- 关闭浏览器：后台继续运行，手机可继续给在线电脑发送任务。
- 网页左侧“完全退出”或任务栏托盘“完全退出”：停止本机 Agent、手机桥接和其运行的任务进程；不关闭浏览器、不停止云端服务、不撤销账号。
- 开始菜单同样提供“完全退出青穗集”。
- 更新和卸载先关闭本机服务，默认保留用户资料与绑定的原始项目，不提供自动删用户数据选项。
- 重复双击复用单实例；端口被占用时明确提示，不接管或杀死其他服务，避免开发版与安装版同时运行。

## 构建

需要 Windows x64、开发依赖、Inno Setup 7 与 .NET Framework 编译器。安装包用户只需 Windows 10 2004+ / Windows 11 x64；Node 22.23.4 随包提供，其 ZIP 按官方 SHA256 校验。

运行 scripts/release/build-windows.mjs，提供以下参数：

- --node-archive：官方 node-v22.23.4-win-x64.zip 的完整路径。
- --inno：ISCC.exe 的完整路径。
- --catalogue-db：包含公共岗位的数据库完整路径，只读提取 catalogue 表；不会复制整库。
- --output：可选，新输出目录，不能覆盖已有交付。
- --skip-build：可选，复用刚完成的构建。

入口命令是 npm run release:windows；如果 PowerShell 的 npm 包装器吞掉参数，可直接用 node scripts/release/build-windows.mjs 加参数。

构建结果为 dist/windows/版本号/ 下的 Setup.exe、portable.zip、build-report.json。每个便携目录另含 SHA256SUMS.txt、第三方许可索引和 Node 许可。只分发编译后可达的本机模块，排除开发环境文件、用户数据库、日志、测试与官方 relay 代码。

## 验证

node scripts/release/verify-windows.mjs [便携目录完整路径] [日志目录完整路径]

此验证只使用独立资料目录和合成本机设备身份，不调用付费模型；覆盖生产网页/素材、首次公共岗位导入、重复启动、网页完全退出、命令完全退出、重启保留资料。

源码还包含退出接口专项测试。安装器需单独验证自定义路径安装、桌面快捷方式和卸载；不能把编译成功当成这些流程已验收。

## 内测边界

- 当前尚未配置发行者代码签名。Windows 可能提示未知发布者或限制运行；不要要求测试者关闭安全保护，应在扩大分发前配置可信签名。
- 此版不自动更新、不自动开机启动；后续版本可通过新安装包更新。
- 本机仍需联网调用官方/第三方模型，官方账号同步与本机执行是独立边界。
- Git、Python、Office 等外部工具未捆绑；缺失时应明确提示，不能宣称全部工具都可用。
- 安装包不包含测试数据库，也不具有清空整个官方账号的能力。
- Inno Setup 的商业许可条件需在商业分发前核对；本次用于内测构建。
