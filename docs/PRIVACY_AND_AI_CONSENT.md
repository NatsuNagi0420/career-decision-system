# 隐私与外部 AI 授权

## 1. 默认规则

- 外部 AI 调用默认关闭；用户必须在 Web 或 Android“我的”中明确开启授权。
- 未授权时，决策教练、岗位比较、行动教练和周复盘教练继续返回本地规则结果，`generationMode=fallback`。
- 授权只影响外部模型调用，不影响账号、职业探索、决策、计划、任务和复盘等核心功能。

## 2. 可发送数据

每次调用只组装当前功能所需的最小上下文，例如：

- 当前决策问题、已确认候选和用户选中的证据摘要。
- 当前目标、当前周任务、已记录成果和本次复盘内容。
- 用户主动要求解释的岗位原始描述。

不得发送：密码、访问令牌、刷新令牌、Agent 内部令牌、数据库凭据、未被当前功能选中的完整档案、其他用户数据或服务日志。

## 3. 数据链路

```text
Web / Android --HTTPS--> Backend
Backend --回环 HTTP + 内部令牌--> Agent Server
Agent Server --仅在已授权且已配置时--> OpenAI-compatible 服务
```

Agent 不直接访问业务数据库，也不写入候选、目标或任务。模型输出先经过结构校验并作为建议返回；涉及新增候选、确认目标或批量调整任务时，必须由用户再次确认后调用后端业务接口。

## 4. 日志与密钥

- 模型 API 密钥只允许通过 Agent 环境变量注入，不进入 Git、客户端包、接口响应或业务数据库。
- `agent_runs` 仅保存脱敏审计信息、结构化结果摘要、运行模式和 Trace ID。
- 请求日志不得记录 Authorization、Cookie、内部令牌、模型密钥或完整个人上下文。
- 真实模型失败、超时或返回非法结构时自动降级，错误信息不得回显密钥或上游原始敏感响应。
- Android 的 Room 离线队列、AI 对话、本机主题和背景不进入系统自动备份；背景派生图移除 EXIF 后保存在应用私有目录。
- Android 存在待同步操作时阻止退出登录，避免以清理本地账号数据的方式丢失成果或复盘。

### 对话正文与审计的边界

- `chat_sessions/chat_messages` 中的对话正文属于用户业务数据，用于同一会话继续提问、稳定重试和展示历史，不属于服务日志。
- `agent_runs` 属于运行审计，只保存脱敏输入/输出摘要、状态、耗时和 Trace ID，不以审计名义复制完整对话。
- 后端只把当前会话最近 12 条截断后的可信历史交给 Agent；只有用户已授权且真实模型已配置时，Agent 才可继续把必要内容发送给外部模型。
- 正式上线前必须在隐私政策中说明对话保存期限、删除入口和账号注销后的处理规则。

## 5. 撤回授权

用户关闭“允许调用外部 AI 模型”后，后续请求立即停止向外部模型发送个人上下文。撤回不会删除已经确认的业务数据，也不会自动删除依法或按产品规则保留的历史审计记录；正式上线前需要在隐私政策中明确保留期限和删除申请渠道。

## 6. 验收检查

- 新账号的 `externalAiConsent` 为 `false`。
- 未授权或未配置模型密钥时，教练接口稳定返回 `fallback`。
- 已授权调用只包含当前任务需要的字段，日志扫描不出现令牌和密钥。
- Web 与 Android“我的”都可修改授权；修改必须写入同一用户档案版本并立即影响后续 AI 请求。
- Debug 和 Release 客户端到后端均拒绝明文 HTTP。
