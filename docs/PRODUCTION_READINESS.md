# 第一版就绪度

## 已完成的工程能力

### 后端与数据库

- Flyway B1 基线、V2 决策行动领域、V3 成果幂等、V4 周复盘文本、V5 档案证据与 AI 授权、V6 周复盘幂等、V7 对话会话、V8 结构化 JD 与方向映射、V9 既有岗位回填。
- 旧用户、报告和路径记录继续读取，不自动伪装成新决策项目。
- 决策项目、2 至 5 个候选、唯一主目标、最多一个备选目标和状态转换。
- 行动计划、统一任务状态、成果、变更历史、周复盘和项目快照。
- Token 用户隔离、越权测试、请求校验、审计脱敏和 Agent 内部令牌。
- 计划、任务状态、成果、周复盘、目标信心、报告快照和批量调整的重复提交保护。
- 档案、决策项目聚合和任务操作使用乐观锁；任务排序整笔校验并回滚，跨端旧版本写入返回 `409`。
- 通用 AI 对话只接收资源选择 ID，真实档案、项目、目标、计划和复盘上下文由后端按登录用户组装。
- AI 对话按用户持久化会话与消息；稳定 `requestId` 支持不重复的失败重试，可信历史限定为最近 12 条。
- 会话管理以增量接口提供活跃会话列表、完整详情、重命名和永久删除；所有查询与写入按当前用户隔离，原有 `POST /chat/messages` 契约保持不变。删除会话会级联清理消息，并擦除关联聊天审计中的可读内容；客户端在发送中、离线或删除失败时不会假装完成。

### Agent

- FastAPI + LangGraph + Pydantic 的受控工作流。
- 决策教练、岗位比较、行动教练和周复盘教练。
- `generationMode`、可信度、依据、反对因素、不确定性和下一步统一契约。
- OpenAI-compatible 适配器、超时重试、非法 JSON/结构降级和敏感日志测试。
- 32 条固定教练评测，覆盖相关性、解释性、格式、重复建议和提示注入。

### Web

- 工作台、职业探索、决策项目、行动计划四区导航。
- 注册自动登录、首次引导、真实岗位、五阶段决策、目标确认。
- 2 至 12 周计划、任务成果、每周复盘和二次确认调整。
- 决策快照、旧报告、简历分析和旧路径计划统一历史记录，以及设置和页面上下文 AI 导师。
- 独立穗奈助手页提供会话列表、详情恢复、继续对话、重命名和永久删除；悬浮导师继续服务当前页面上下文，并在独立助手路由隐藏以避免重复入口。
- 档案证据主动引用、岗位三段式证据匹配、兴趣筛选和目标岗位管理。
- 1440px 与 360px 完整 Playwright 闭环，无水平溢出。

### Android

- 注册自动登录、三步轻量引导和加密草稿；`MainActivity` 仅作为导航与通知路由入口。
- 界面拆为今日、目标、AI 导师、我的；Compact 使用 Navigation Bar，Medium 使用 Rail，Expanded 使用 Permanent Drawer。
- Repository、远程数据源、ViewModel、Room 和 WorkManager 分层。
- Keystore 会话、刷新令牌并发单飞、统一错误、永久 401 回登录、HTTPS-only Debug/Release。
- 离线完成/延期/跳过、成果、目标信心和快速周复盘队列，联网后使用稳定 `requestId` 恢复同步。
- Room v5 保存任务版本、AI 当前会话与原生历史缓存；冲突操作不会静默覆盖或无限重试，聊天失败可用同一请求重试。
- “我的”二级页可查看、筛选和打开决策快照、旧报告、简历分析与旧路径计划；详情可离线回看，删除前说明影响范围，复杂生成仍留在 Web。
- AI 导师可列出服务端历史会话、打开并继续跨端对话；打开远端会话后替换当前 Room 缓存，不把首版实现表述为多会话完整离线镜像。
- 任务与周复盘提醒默认关闭并显式请求通知权限；退出登录取消当前用户提醒。
- 项目 M3 组件、Lucide 图标、Light/Dark/跟随系统、真实系统动态颜色、种子色/图片取色生成完整语义方案、对比度和 Android 独立背景已接入；取色与设置背景是两个独立动作。
- 登录/注册只动画差异字段，一级页面使用统一 Fade Through，历史等二级页面使用 Shared Axis；恢复默认主题和退出登录需要确认，待同步操作会阻断退出并引导先同步。
- 业务页面静态门禁禁止 Material 2、Material Icons、直接 Material 控件、硬编码颜色和形状。
- Debug/Release APK、Lint 和 94 条 Android 单测通过。
