# 文档索引

这里保存当前产品的设计依据、Agent 运行边界、岗位库规则、研究资料和穗奈品牌交接资料。运行时代码只在 `agent/` 和 `web/`，文档不会被服务自动加载。

| 目录 | 用途 |
| --- | --- |
| `architecture/` | 当前仓库结构和系统边界 |
| `agent-foundation/` | Agent 执行、模型、沙箱、文件成果和数据库 |
| `v2/` | 当前产品目标、对话工作流、岗位匹配和 UI 决策 |
| `岗位库扩充/` | 岗位数据字段、清洗规则、批次和导入说明 |
| `品牌形象/` | 穗奈原画、Live2D 交接和网页素材制作资料 |
| `参考资料/` | 论文、开源项目和研究工具 |
| `季度报告/` | 阶段性进度与试点记录 |
| `v1-历史/` | 历史设计文档，仅供追溯 |

原始 PDF、PSD、KRA、ZIP 和网页抓取物只在本机或制品存储保留，不作为应用运行时输入。新增产品结论请优先更新 `v2/` 或 `agent-foundation/` 中对应文档，并同步架构索引。
