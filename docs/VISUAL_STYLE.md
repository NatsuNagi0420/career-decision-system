# Visual Style

> **2026-10-16 — Historical direction, not the active Web theme.** The cyan virtual mentor, purple ban, energy maps, and sync-rate ideas below are archived concepts, not requirements for the current career desktop. For the active Web appearance, see `web/src/desktop.css`; for Suinai asset production, see [desktop asset v2](品牌形象/桌面素材扩展v2/制作说明.md). This scope notice does not change Android requirements.

## Direction

The product should feel like:

```text
AI career planning + cyan virtual mentor + electronic music interface + professional planning tool
```

Anime concentration can be high, but forms, reports, resumes, and planning information must remain readable and practical.

## Palette

Primary:

- Miku cyan: `#39C5BB`
- Neon cyan: `#00E5D4`
- Ice blue: `#7DEEFF`

Neutral:

- Deep background: `#071013`
- Dark panel: `#111C20`
- Light background: `#E9FFFB`
- Main light text: `#EFFFFC`
- Dark text: `#1F2933`
- Border: `#D8E5E3`

State:

- Success: `#2ED8A3`
- Warning: `#FFB84D`
- Danger: `#FF5A5F`

Forbidden:

- Purple
- Pink-purple
- Blue-purple gradients
- Purple glow effects
- Generic AI purple-blue gradient backgrounds

## Motifs

- Original cyan-haired virtual career mentor
- Audio spectrum bars
- Waveform lines
- Data streams
- Thin glow borders
- Skill energy maps
- Career sync rate
- Growth route timeline

Do not use official Hatsune Miku art, logos, names as branding, or copyrighted materials in the product UI.
