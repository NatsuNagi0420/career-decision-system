# ASCII 微交互（2026-10-23）

## 设计取舍

采用 ascii.rest 的低对比、等宽字符语言，作为像素桌面的轻量补充，不替代穗奈，不把整个工作台改成黑色终端。

- 左下角：缓慢呼吸、摆尾、飘出 Z 的字符猫；不占聊天正文。
- 欢迎页：字符边框式眉题、卡片编号括号；鼠标悬停或键盘聚焦出现一次短促的字符星点。
- 对话状态：等待模型是点阵等待符；真实工具开始执行后为扫描符。原始操作名称、命令、耗时、结果仍由现有事件驱动。
- 等待确认：静态时钟，不持续播放「执行中」动画。
- 文件预览：文件图标与字符弹跳符；预览完成即移除。生产接口不增加人为等待时间。
- 右上角：`[~]` 为开启，`[·]` 为静止。按钮标题解释含义，并有可访问名称与按下状态。

## 不使用的内容

不将示例 terminal、boot-log、pipeline、progress-bar、随机数据仪表盘当成真实执行日志、任务计划或百分比。没有新增模拟模型思考、伪造工具调用，也没有打乱中文正文来制作文字解码效果。

ASCII 微交互改善的是等待反馈和手感，不改变 Agent 的规划、工具与职业功能能力。

## 来源与许可

- 网站：https://ascii.rest/
- 官方仓库：https://github.com/bas3line/ascii
- 本次锁定版本：`ascii.rest@0.4.0`（MIT）。只直接引入 `cat` 和 `spinners` 两个素材模块。
- 原始许可随产品保存到 `assets/web/brand/licenses/ascii-rest-MIT.txt`，由后端资源入口 `/api/assets/brand/licenses/ascii-rest-MIT.txt` 提供。
- 本地打包，无 CDN 脚本、远程字体、iframe 或第三方运行时请求。
- 字符画不是新图片资产；仍然使用现有统一图片资源 API，不绕过私有文件鉴权。

## 代码位置

- `web/src/agent/asciiPieces.ts`：精选素材和固定网格裁边。
- `web/src/agent/AsciiArt.tsx`：复用播放器、静态首帧和动效开关。
- `web/src/agent/uiMotion.ts`：独立偏好存储，键为 `career.uiMotion`。
- `web/src/agent/ascii-interactions.css`：字符画等宽字体、有限次悬停效果和响应式尺寸。
- `web/src/agent/ascii.test.tsx`：网格稳定、偏好、装饰语义和真实任务状态测试。

## 性能与无障碍

- 最高 8 FPS，帧更新只写字符画容器，不通过 React state 逐帧刷新聊天。
- 复用官方播放器的可见性与页面前后台观察；屏幕外或页面隐藏后不继续绘制；卸载时回收。
- 尊重系统 `prefers-reduced-motion`，系统减少动态优先，静止时仍保留完整信息。
- 用户可通过右上角关闭；偏好持久化并跨标签同步，存储不可用时降级为内存偏好。
- 不改变独立的 `career.motion` 角色动作设置。
- 字符画 `aria-hidden`，不逐帧向读屏播报；真实状态使用旁边的中文文字。
- ASCII 使用真正等宽字体，中文 UI 保留现有像素字体。

## 快速验收

1. 刷新工作台，新建对话；查看左下角字符猫、欢迎卡片的鼠标/键盘焦点反馈。
2. 关闭右上角界面动效，再刷新；图案静止，设置保留；穗奈动作控制独立。
3. 发起真实任务：等待模型 / 真实工具执行应分别显示点阵 / 扫描符；结束或停止后不再加载。
4. 点击文件名：只在实际请求期间出现读取反馈，之后呈现真实文件内容。
5. 独立界面支架：在 `agent` 目录运行 `node node_modules/tsx/dist/cli.mjs test/execution-browser.ts --ascii`。端口 8112，独立临时数据库，测试会话明确标记；无真实模型和宿主命令执行。预览响应只在支架中延迟 2 秒以便观察加载符。
