# 文件链接与预览侧栏

- write_file / publish_file 成功返回 artifact 和 link。模型在消息中使用 [文件名](artifact:真实ID)；前端仅映射本用户快照里登记的文件，不把任意本机路径当作可访问链接。
- 左键预览；右键提供预览、下载，本机再提供默认应用打开/所在文件夹。生成但未在正文引用的文件补为文字链接，不用成果卡片。
- 侧栏支持 Markdown 排版/原文、JSON 格式化、CSV 表格、UTF-8 文本、PNG/JPEG/GIF/WebP、浏览器 PDF 预览。HTML/SVG 仅源码；Office/ZIP 等明确提示不支持在线预览，仍可下载。
- 文本最多预览 120,000 字符，CSV 最多 200 行/40 列。单文件沿用当前 1 MB 限额，Word/PPT 原版式转换不在本次范围。
- 下载沿用登录、归属、版本 SHA256、用户确认和时限审批，不生成公开分享链接；私人文件不走公共 /api/assets。
- 本机打开需 AGENT_DEPLOYMENT_MODE=local 且连接来源、Host、Origin 均为本机。只接受已登记文件 ID，不接受任意系统路径；脚本、可执行程序、网页、宏文档不会交给默认应用执行。
- 打开的是 dataDir/local-open/文件ID/原文件名 的版本副本，保留扩展名；编辑不会同步原始成果。已被编辑的副本不会被覆盖，改用下载获取新副本。
- 服务器部署必须设 AGENT_DEPLOYMENT_MODE=server，隐藏并拒绝本地应用操作。该标记不代替公网部署：当前本机 Host/回环限制、HTTPS/反代、外部鉴权/存储等需另行配置与验收。

验收记录：项目 logs/file-link-preview-20261022。浏览器使用独立账号、临时数据库与明确标识的测试文件；系统应用通过测试替身验证，不启动真实应用或调用真实模型。
