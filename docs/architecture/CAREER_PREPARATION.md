# 岗位决策、练习与文字面试

## 体验路径

- 职业工作台 → 方向与岗位 → 比较岗位：围绕已保存的 2–3 个岗位，对照吸引点、准备成本、取舍和未知项。用户决定首选与备选，可保存理由；画像或岗位变化后提示重新比较。
- 职业工作台 → 学习路线 → 开始练习：选择目标岗位、形式与题数。岗位练习与试卷回到当前主对话；模拟面试打开独立窗口，点击“开始面试”后出题。入口不自动创建新会话。
- 岗位练习：可选按岗位现场出题，或从整理题库搜索并选题。一次一题，答后讲解。
- 模拟试卷：现场生成试卷，逐题作答，交卷前隐藏评价与参考答案，结束后查看复盘。
- 模拟面试：独立通话窗口中，穗奈出镜担任模拟考官，右侧展示当前问题，下方打字作答。背景、考察点和上一题反馈可按需展开；先问一题，再根据回答追问。复用现有角色与背景素材，不调用摄像头或麦克风。结束后旧轮次保留为复盘；“再来一轮”沿用岗位与题数创建新轮次，不恢复已结束的轮次。
- 对话输入栏上方显示本轮进度，支持暂停、恢复、结束及回看记录。面试窗口最小化后保留进度和未发送草稿，任务栏可重新打开；关闭进行中的窗口会暂停面试。提前结束会保留已提交回答和逐题复盘。薄弱点可交给穗奈调整学习安排，仍需按原学习流程核对。

## 数据与执行

`CareerPreparation` 由 `CareerWorkspace` 持有，复用当前 SQLite，不增加另一套数据库。

- `career_preparations`：按 `user_id` 保存版本化决策板与训练会话。会话记录岗位原文快照、模拟背景、考察重点、题目、答案和反馈。
- `preparation_turns`：标记模拟轮次，随运行记录删除。运行中及后续后台分析均排除这些轮次，避免虚构的模拟回答成为职业事实或长期记忆。
- `read_career_preparation`：读取公开记录与整理题目录。
- `propose_job_decision`：校验岗位、版本和逐字引用，保存比较草稿，不替用户选择。
- `start_career_preparation`：校验岗位与题数，启动一轮。整理题从服务端按 ID 取题；面试只准备首题，试卷先准备整套题。
- `review_career_answer`：仅接受当前会话、当前题、本轮用户实际发送的完整回答；同轮重试不重复记分。面试追问必须引用本轮保存的岗位原文。

前端通过认证接口读取公开视图；未作答题目不返回评分依据与参考答案，试卷结束前也不返回作答评价。面试窗口复用当前会话、运行队列和训练状态机，不另建一套聊天记录。开始与评价成功后，由工具返回确定性的题干和反馈，前端复用聊天区的解码显字动效；这是收到结果后的呈现动画，不是伪造模型正在逐字生成。

编辑并重新发送答案时，状态机会截断该题及其后的回答，面试同时删除旧追问；回退启动消息会移除该分支的训练记录。永久删除会话时同时清理对应训练与决策记录。

Windows 资料清理允许系统对应用资料目录的实际路径映射，按固定管理目录的规范路径定位会话；显式链接、目录联接、子树链接以及删除前路径变化仍会被拦截。

## 题目来源

首批为 12 道原创整理题，覆盖 JavaScript、TypeScript、React、HTTP、SQL、事务、测试、Python、可访问性、Git 与数据处理。每题保存参考资料名称和链接，题干及参考思路为重新整理的内容，未搬运企业题库，不声称企业真题。

参考资料包括 MDN、TypeScript Handbook、React、PostgreSQL、Python、W3C WAI、Git、pandas 与 ISTQB。2026-11-13 检查了全部来源链接，结果见 `logs/preparation-20261113/question-sources.json`。可访问不等于题目获得该组织认证。

现场出题、试卷与面试追问标为 AI 生成。其他岗位可由模型按已保存的 JD 出题；当前整理题库主要覆盖开发与数据基础，尚未覆盖所有职业。

## 角色与反馈边界

穗奈在提问、倾听、分析、鼓励、安慰与完成一轮时复用现有动作；动画开关和系统减少动态偏好继续生效。评价只针对这次作答，不转换成性格、能力认证、录用概率或技能等级，也不自动标记学习完成。

岗位取舍文本与作答评价来自当前模型，仍可能有误；程序保证来源校验、轮次对应和状态流转，不保证模型判断的客观正确性。本次没有新增 Jev 评分链路。

本机与云端复用相同运行时和账号隔离接口，云端继续遵守原沙盒边界。本次只更新本机开发服务，没有发布云端。
