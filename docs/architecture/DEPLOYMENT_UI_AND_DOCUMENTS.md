# 部署界面与文档导入

## 单份前端、服务端能力清单

环境入口继续使用 `AGENT_DEPLOYMENT_MODE`。`agent/src/ui-contract.ts` 生成公开的界面能力，HTTP info 接口提供 `ui`，前端的 `resolveDeploymentUi` 集中兼容旧服务。加载期间按已确认的认证模式呈现，未知模式不展示本机高权限入口。能力清单不包含密钥、内部模型或路由。

云端隐藏模型连接设置、模型选择、本机项目绑定、宿主机权限菜单和桌面退出；文件预览无系统打开操作。思考强度与资料上传保留。设备窗口复用布局，按运行形态选择 PC bridge 或 Hub 数据，不在云端注册服务器为用户电脑。

账号授权独立于 UI 开关。云端注册页不展示重复模型勾选；未授权的账号首次调用前使用现有确认弹窗告知并提交授权。撤回授权后的后台校验仍保留。云端官方连接未测试时在发送流程按需测试；上游故障不能打开已隐藏的模型配置页。

后端继续禁止 server 的 full-access、本机目录登记和本机应用打开。当前云端的默认 `AGENT_SERVER_COMMANDS=false` 未改变。本功能不宣称每用户拥有容器隔离。

## 文档处理

- 正文：PDF 使用 unpdf，DOCX 使用 mammoth；没有新增 OCR、Office 或系统命令依赖。
- 输入：4 MiB，PDF 40 页，正文 200,000 字符；每个服务进程最多两个解析线程、15 秒超时、每线程 192 MiB 老生代上限。独立线程是资源控制，不是操作系统沙箱。
- DOCX：读取 ZIP 目录校验条目数量、解压声明大小、路径及本地条目一致性，拒绝宏包、加密或损坏文档。
- 提交前解析失败不生成附件；没有正文时提示文字版 PDF／DOCX，旧 DOC 不按 DOCX 冒充处理。
- 原件保持 SHA-256 和不可变版本，下载仍走现有授权与审批。
- `read_file` 对原文件路径返回提取正文，沿用 offset/limit；不另生成可被用户误改的正文副本。最近八份提取结果缓存于当前进程内，重启清空，访问仍先通过文件归属和路径检查。
- PDF 预览原件；DOCX 预览正文，不渲染外部图片、宏或 HTML。图片保留原有当前轮多模态通道，是否识别仍取决于所选模型的视觉支持。

## 发布

后端有新运行依赖，云端不能仅替换 Web 静态文件；需要发布新编译代码和 package-lock，重新安装生产依赖。依赖目录必须允许服务账号读取，但账号数据库和私密 env 仍保持原有权限。Windows 安装包需单独重新构建，本轮不覆盖已交付安装包。
