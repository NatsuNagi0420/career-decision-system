# 穗奈入门引导

## 体验

首次进入用六段简短介绍串起产品能力：聊天形成职业画像、用真实材料梳理经历、岗位推荐及经历对照、学习计划与成长行动、实时简历预览与框选修改、可查看和纠正的识海记忆。每段同时指向真实入口，保留用户提供的透明底板和现有穗奈头像，不暴露内部模型分工。

区域高亮与气泡跟随实际控件；窄屏使用顶部工作台按钮和底部识海入口。文字和按钮为 DOM，不依赖图片文字。模式步骤只介绍入口，不替用户切换任务；完成后才回到输入框。

新用户创建时初始化 `pending`。账号已经登录、工作区信息已加载、启动动画退出后，且没有输入草稿、运行任务或设置窗口打断时自动开始。本机首次模型设置优先于教学。旧账号缺少记录时返回 `legacy`，不因升级强制弹出。

支持下一步、返回、直接选步骤、跳过、Esc 和顶部问号重看。完成后仅聚焦输入框，不自动填入或发送消息；不调用模型，不生成假聊天、画像或附件。教学期间暂停闲置招呼与意图分析。

## 进度

`user_onboarding` 与账号在同一 SQLite 数据库，外键随账号删除。状态由 `/api/v1/agent/onboarding` 的 GET／PATCH 获取与更新，接口只操作已登录账号，输入严格校验。纯 Hub 转发模式也可记录教学，不因此开放执行权限。

新本机工作区、首次映射的官方账号、普通注册账号都初始化；再次 bootstrap／身份验证不重置。完成与跳过状态不能被延迟到达的步骤请求覆盖。中途刷新按已保存的最远步骤继续。浏览器仅保存按账号、版本与运行形态区分的完成／跳过兜底；恢复连接后补写。

步骤顺序及上限共用 `onboarding-contract.ts`，原有前三步顺序不变，已完成或跳过的老用户仍可从问号重看六步，不强制重播。

进度以当前服务的账号记录为准，不新增云端与电脑之间的教学进度同步协议。当前版本为 1，不对旧用户强制播放全套教程。

## 视觉与边界

素材位于 `assets/web/brand/onboarding/`，经已有 `/api/assets/` 路由获取。图片只裁透明空白、无损转 WebP；像素边框以九宫格拉伸，文字、指向和按钮实时渲染。

`OnboardingTour` 使用原生模态 dialog 避免误操作底层按钮；可 Esc 退出、恢复焦点，尊重减少动态效果与界面动效设置。定位测量响应视口、滚动与控件尺寸变化，不固定屏幕坐标。缺少目标时保持说明可见，不画错误高亮。

云端不介绍本机项目入口、模型连接或宿主机权限；本机资料步骤补充项目文件夹入口说明。教学不调用任何特权操作，也不修改既有云端执行边界。
