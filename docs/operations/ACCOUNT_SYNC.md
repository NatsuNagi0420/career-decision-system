# 官方账号资料同步

同一官方账号的积分来自 Relay，聊天与记忆通过 Cloud Hub 同步。积分一致不能证明资料已上传。API-KEY 本机身份、旧测试账号和不同官方账号的数据各自隔离。

## 行为

- PC 登录官方账号并配置 `AGENT_CLOUD_URL` 后自动登记同步连接，无需手机配对。已有记录会逐批补传，记忆每 15 秒增量交换。
- 手机扫码仍单独授权远程执行。待配对、二维码过期时允许同步，但不能下发或认领电脑任务。
- 主历史列表合并本端和跨端会话，用电脑或云端图标区分执行位置；点击跨端记录打开会话窗口。云端原生会话也可从电脑查看。
- 记忆使用原有版本协议双向合并，保留证据、冲突处理和删除墓碑；关闭“随官方账号同步”会暂停记忆交换。
- 云端改名、归档、删除的电脑会话会回传；电脑执行期间延后应用。删除后保留同步墓碑，离线旧数据不能复活该会话。
- 断开电脑连接后不会自动重新登记；需在“设备与同步”重新连接。退出官方账号停止该账号的同步。

## 边界

会话同步共享可见消息与进度，不将另一端的运行日志、沙盒或模型凭据复制进本端 Runtime。电脑任务继续在原电脑执行；它离线时同步历史仍可查看，已配对任务等待电脑上线。

职业工作台仍维护各执行端自己的状态；电脑的职业资料以设备快照保存在 Hub，不自动覆盖云端职业工作台。单个同步文件限 4MB；原项目文件夹不会整包上云。

## 排查

先确认 PC、网页登录的是同一官方账号，再检查本机服务是否运行、`AGENT_CLOUD_URL` 是否正确、同步是否关闭、凭证是否有效。只按账号统计 `conversations`、`memory_nodes`、`remote_connections` 与云端 `hub_sessions`，不要输出令牌或资料正文。旧账号资料需要用户明确选择后迁移，不能仅按用户名自动合并。

回归覆盖：无需扫码同步、配对过期、跨账号拒绝、云端改名和删除回传、记忆开关，以及云端原生历史的跨端读取。模型和官方登录使用测试替身，不产生上游计费。
