# 本机测试账号与预置资料

在本机 Agent 启动、官方账号服务可用后，于项目根目录运行：

```powershell
npm run test:account
```

命令通过现有账号接口注册一个普通官方测试账号，并在当前本机数据库中初始化以下虚构资料：

- 三段可继续的对话：画像与岗位、学习路线、修改与导出简历。
- 软件工程应届生的画像、四项技能记录、一个虚构岗位、岗位差距与两项行动。
- 三章学习路线，分别处于已完成、进行中、待开始状态；教程可在页面中真实搜索。
- 带原文依据、岗位取舍与确认状态的简历，可预览、修改和导出。

创建账号会访问配置中的官方账号服务。模型连接会做真实聊天、流式与工具调用探测，消耗少量正常额度。没有真实调用的预置内容均明确标记为测试资料，不是模型生成结果，也不代表真实人物能力。

用户名和随机密码只保存在 `AGENT_DATA_DIR/development-test-account.json`，默认位于当前用户的应用数据目录。终端仅显示用户名和凭证文件位置，不输出密码或令牌。不要提交、上传或分享该凭证文件。

只支持本机模式，且仅接受命令创建的专用测试身份。资料通过现有职业、学习、简历状态机写入，同一事务失败会回滚；已有内容的未标记账号会拒绝初始化。再次运行复用原测试号，保留测试时的修改，不恢复初始状态。不要删除凭证文件来“重置”，否则会另建账号。

这些预置资料位于当前本机实例。用同一账号登录另一台电脑或云端，并不自动得到这套本机测试资料；是否同步取决于实际设备连接与同步配置。
