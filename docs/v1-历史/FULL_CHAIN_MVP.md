# 第一版全链路状态

## 用户闭环

```text
Web 注册与引导
  -> 职业方向与真实岗位探索
  -> 2 至 5 个候选的决策项目
  -> 确认主目标和备选目标
  -> 生成 2 至 12 周行动计划
  -> Web 或 Android 完成任务并记录成果
  -> 提交每周复盘并确认计划调整
```

## 数据流

```text
Web / Android
  -> HTTPS Backend（认证、用户隔离、事务、MySQL）
  -> HTTP Agent（仅本机内部令牌）
  -> LangGraph 规则基线
  -> 可选 OpenAI-compatible 模型
  -> Pydantic 结构校验
  -> Backend 审计与业务持久化
```

Agent 只提出候选和修改建议，不直接写数据库。用户确认后由后端业务接口写入。

## 已完成

- Flyway B1/V2-V9，V8 增加结构化 JD 与稳定方向映射，V9 受控回填既有岗位；旧报告和旧路径接口继续兼容。
- 职业目录、个人证据、决策项目、候选、岗位样本、比较、目标。
- 行动计划、成果、变更历史、每周复盘、项目报告快照和工作台聚合。
- Web 四区导航、五阶段决策、行动计划、复盘、页面上下文 AI 导师，以及可恢复和管理历史会话的独立穗奈助手。
- Android 注册/登录与轻量引导、四页行动端、快速成果和周复盘、目标里程碑与信心反馈、跨端 AI 会话历史、原生决策历史、通知提醒、完整动态配色与同步状态。
- Android Keystore 会话、刷新令牌并发单飞、Room v5 缓存、WorkManager 离线队列和永久认证失败回登录。
- 计划、任务状态和任务成果使用 `requestId` 防重复提交。
- 32 条固定 Agent 教练评测和真实模型配置模板。
