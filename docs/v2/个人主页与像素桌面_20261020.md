# 个人主页与像素桌面 · 2026-10-20

## 使用入口

打开本地前端 `http://127.0.0.1:5174/` 并登录。左侧原“我的档案”升级为“个人主页”。底部用户名、欢迎页链接、右侧便签和账号菜单均可打开主页。

主页四个栏目：

- **主页概览**：学校、专业、毕业年份、意向城市、个人简介；真实经历与成果数量；基于已有资料和文件的下一步提示。
- **经历与技能**：本人添加、编辑、按分类查看和撤回已确认经历。保存操作直接表达本人确认，不调用模型。
- **成果文件**：已保存画像分析可在主页查看，岗位对照、学习路线、简历进入对应窗口。草稿与已确认成果分开标示。
- **账号设置**：云端模型授权、界面动画和退出登录，复用既有账号接口。

基本资料和经历条目各自维护。修改学校、专业、年份后，也应检查以前写下的教育经历是否一致。旧报告和简历不会静默改写；应让穗奈基于新资料重新分析或生成。

## 视觉变化

- 正式产品界面统一使用已有本地 Fusion Pixel 中文像素字体；输入框、历史对话、成果卡、菜单和登录页跟随统一字体。
- 12px 为字体原生基准；大屏主要阅读区域使用 24px，提高可读性；保留缺字回退和字体许可。未依赖外部字体服务。
- 桌面在超宽视口限宽居中；大屏字号、角色和窗口比例单独调整，欢迎内容与输入框相邻。
- 个人主页按实际窗口宽度变为两列或单列，手机缩短页头并保留底部主页入口。
- 历史侧栏支持长标题换行、完整悬停文本和分层待办；去掉字符串预先截断造成的信息丢失。
- 简历工具栏、缺项提示、正文分区。联系信息可在当前预览填写，复制与打印一致。联系信息暂不保存，切换或离开简历后需重新填写。
- 正式简历正文和 PDF 使用系统文档字体，保证投递版可读。打印隐藏工具栏、缺项、桌面背景和阴影；缺项仍可在编辑页补充。

## 数据与并发

新增私人档案接口，无数据库迁移：

- `GET /api/v1/profile`
- `PUT /api/v1/profile`
- `POST /api/v1/profile/facts`
- `PUT /api/v1/profile/facts/{id}`
- `DELETE /api/v1/profile/facts/{id}?expected_version=...`

全部使用当前登录者身份，拒绝跨账号读取或修改。写入携带资料版本，过期版本返回 409，界面保留原输入并提供重新读取。提交中禁用表单，防止重复点击与覆盖新输入。

编辑经历生成新记录并撤回旧记录；撤回仅使旧记录不再确认，保留历史原文引用。画像工具、岗位/比较读取和简历组装排除已撤回经历。新增“实习与项目”分类进入画像读取和简历对应章节。
