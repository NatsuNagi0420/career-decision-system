# 青穗集 · 当前任务与穗奈陪伴（2026-10-23）

## 交互原则

主对话始终是入口。任务按钮不是独立页面，也不是仅往提示词里插入一句“进入模式”。用户可在当前对话选择“找职业方向”“定学习计划”“写／改简历”，暂停和切换后保留聊天与任务 ID。点击不会自动发消息，也不会提升命令权限。

穗奈可以猜测意图，但猜测只是待接受的建议；后台分析器无工具权限，不能启动任务、修改画像、写文件或导出。用户直接在自由对话中明确提出的简历请求仍兼容旧工具流程；显式简历任务使用更窄的工具白名单和程序关卡。

## 前端呈现

- 输入框上方：任务按钮与简短阶段提示，避免五步表单。
- 角色窗口：用户提供的透明像素气泡承载建议或闲置问候，保留现有穗奈模型。长建议最多显示三行，可悬浮查看完整文字。
- 侧栏：用“聊到了这里”替代独立的“执行环境与边界”，展示模型小结和下一步。展开可看到“非已确认档案”的提示，小结不自动写入职业画像。
- 执行权限的真实边界仍在输入栏权限菜单中，不以删除面板的方式隐藏风险。
- 窄屏自动收起角色侧栏；建议转为输入区旁的紧凑提示。用户仍可手动展开角色。
- 穗奈小窗右上角的“陪伴互动设置”可分别关闭智能建议/小结与闲置问候，偏好按本机账号保存。

## 简历的程序关卡

任务与阶段在后端校验，不只靠模型遵循提示词：

1. 无原文：先聊真实经历或导入文本。
2. 有原文、无事实草稿：程序准备 facts 整理请求。
3. 有事实、未本人确认：等待用户核对，不能进入取舍。
4. 事实已确认、无取舍：程序准备 selection 请求。
5. 取舍未本人确认：等待核对，不能进入正文。
6. 取舍已确认、无正文：程序准备 rewrite 请求。
7. 已有正文：预览、微调、本人确认后由程序排版。模型如需改写已有正文，只能申请 rewrite，不重置已确认事实或借命令/通用文件工具绕过确认。

简历工具可通过 source.message_id 引用当前对话中的既往用户消息。read_resume_context 提供有限的最近原话索引；引用须匹配真实用户消息 ID 和逐字内容。拒绝助手消息、其他对话消息和模型生成的 outputs 文件作为经历来源。未提供 ID 时保持本轮原话的兼容行为。

当前仍是一账号一份共享简历草稿，不等同于每任务独立简历：在另一对话接续时需确认复用；原对话的简历任务自动暂停，避免两边同时改写。同账号其他对话有任务运行时，暂不允许接管。既有简历历史和成果文件版本仍保留。真正的多岗位独立版本需要后续引入独立简历实体，不能靠模式名字假装实现。

## 意图分析与成本

- 仅对本页新发送且正常结束/等待补充的轮次自动分析；打开旧聊天不会自动把历史再次发送给模型。旧聊天可点击小结刷新手动整理。
- 使用当前用户选择的已测试模型连接，使用既有外部模型授权，不额外要求用户配置第二个模型。
- 前端只提交 conversation_id、profile_id 和已发送 message_id，不提交输入框草稿。服务端只读最近 6 条用户/助手文字，单条最多 1600 字，工具结果不进入分析器。
- 分析输出只接受通过 Zod 验证的 JSON，小结 360 字以内、下一步 100 字以内、建议 90 字以内；建议必须引用真实的最近用户消息 ID。
- 每次输出预算 600 tokens，超时 15 秒，账号接口限流 6 次/分钟；成功结果按最后用户消息去重，失败不会阻断主聊天或无限自动重试。
- 对话换新消息、切换任务、取消授权、退出账号或删除对话时取消过时分析；前后端均拒绝过期结果。客户端取消连接也会停止后台分析。
- 这是额外模型调用，会有供应商用量成本；当前不合并到主运行 token 统计中。可在陪伴设置关闭。

## 闲置互动

闲置问候是本地页面级提示，不是后台通知服务：页面可见、有焦点、约两分钟无操作且没有输入草稿/执行/弹窗任务时才出现。十分钟冷却，每次打开页面最多两次；不会因用户离开而施压，不写入聊天记录，不额外调用模型。关闭页面后不会继续提醒。冷却时间按本机账号保存。

## 接口和实现定位

- POST /api/v1/agent/conversations/:id/task：版本化选择/暂停任务，必要时确认复用共享简历。
- POST /api/v1/agent/conversations/:id/insights：只读小结/意图建议，拒绝草稿等未知字段。
- SSE guidance.updated：同步任务、小结与阶段变化。
- 后端核心：agent/src/guidance.ts、guidance-contract.ts、runtime.ts。
- 前端组件：GuidedTaskBar.tsx、SuinaiBubble.tsx、ConversationMemory.tsx。
- hooks：useConversationInsights.ts、useCompanionNudge.ts。
