## 实现与边界

`main.tsx` 按需加载业务 App；`StartupGate` 显示启动层直到 React 页面提交。此“就绪”指页面模块可以显示，不意味着后端鉴权、资料或云模型已就绪。没有伪造百分比、连接模型或资料加载完成文案。

- 真实 Lottie 源：`web/public/projects/qingsuiji-boot/scene-1/lottie.json`，60 fps，78 帧，透明背景。
- `BootTitle` 按需引入官方 `lottie-web` 的轻量 SVG 构建；Skottie 只用于本地素材验收，不把 WASM 编辑器装进产品。
- 字体来自项目已有的 Fusion Pixel（OFL）。固定字标有意采用逐字路径蒙版，动画和同源 poster.svg 不依赖外部字体；许可与素材同目录。
- 静态 HTML 在首个 JS 模块之前展示同源标志，减少空白首屏。
- Lottie JSON 或播放器加载失败时回到静态标志。页面模块失败则退出动画，显示刷新重试；慢于 6 秒会显示重试提示。
- 全站暂停、系统减少动态下不载入 Lottie。隐藏标签页暂停，卸载销毁播放器。
- 点击跳过只跳过动效，不能绕过尚未加载的页面模块；就绪后焦点交给用户名或对话输入框。
- 这是页面加载与品牌展示，不启动业务任务，不修改用户、密码或云端模型授权。
