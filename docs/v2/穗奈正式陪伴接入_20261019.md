# 穗奈正式陪伴接入（2026-10-19）

## 本轮交付

新穗奈已进入正式求职桌面的陪伴窗口，不再仅存在于动作试映室。沿用现有分层原画和动作，不生成新素材，不更换整站主题，不修改简历或画像的后端业务逻辑。

这是 **Canvas 原画分层连续网格渲染** 的正式页面接入，**不是** 已完成 Cubism 绑定、导出 `.moc3` 的原生 Live2D 模型。原生建模仍是独立后续任务。

## 一条状态来源，而不是另一套 agent

`App.tsx` 继续消费既有任务事件，通过 `reduceFrame` 保存事实；`companionCue` 从当前任务的事件和服务端快照生成反馈；`SuinaiCompanion` 负责展示与一次性动作收尾；正式页和试映室复用 `SuinaiMotionCharacter`。

不根据模型回复中“完成”“成功”“导出”等措辞猜测状态，不根据用户点开的页面猜测正在运行的能力。

| 真实状态 | 正式页面反馈 |
| --- | --- |
| 无任务、正在阅读 | A02 安静陪伴 |
| 输入未发送 | A03 倾听；不会整理或保存输入 |
| 提交请求、读取进度 | A38 稍等；禁止重复提交 |
| 画像／岗位／简历处理中 | 按服务端实际能力映射 A09／A14／A31 |
| 待用户确认 | A37；确认前不提示保存成功 |
| 服务端提案 applied 且 result 非空 | A13／A04，一次性反馈后回到安静陪伴 |
| 已返回报告或简历草稿 | 映射对应展示动作；不等于业务资料已保存，更不等于文件已导出 |
| 依据不足、结果仍未确认 | A12 核对；不庆祝完成 |
| 用户拒绝 | 取消、停止本次写入；不是失败 |
| 服务端失败 | A39，使用现有失败阶段说明 |
| 连接重试耗尽 | 连接暂时中断；不推断后台任务失败；可仅重连进度，不重新创建任务 |

成功类一次性反馈不会随 token 更新、成果刷新或导航重复播放。打开历史对话、刷新旧结果时保持安静，不重播成功动作。没有实际上传或导出事件，因此本轮**不接** A30 收到简历文件、A36 导出成功，也不虚构答题正确或里程碑事件。

## 使用和容错

- 正式首页：`http://127.0.0.1:5174/`，不要带 `?preview=suinai-motion`。
- 桌面右侧直接展示；窄屏右上角通过“穗奈的小窗”展开，支持关闭与 Escape 返回按钮。
- 角色暂停偏好会保存；全站动画开关、系统减少动态设置同样生效。
- 隐藏陪伴窗口或浏览器标签页后停止连续绘制。
- 素材加载失败只影响角色区域，保留对话输入，并提供重新加载按钮。
- 切换／新建对话会隔离旧流、旧快照；旧请求晚返回不会抢走当前对话。
- 保留原有动作试映室用于检查素材、手势和表情；素材 ZIP、PSD 未改。
