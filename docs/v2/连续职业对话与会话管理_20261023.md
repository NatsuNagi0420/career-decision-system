# 连续职业对话与会话管理（2026-10-23）

## 本次纠偏

穗奈的核心是通过持续交流帮助用户认识自己、比较方向、明确要学什么并落实行动。简历在需要求职时按需产生，不再设成独立主流程，也不实现尚不存在的自动平台投递。

旧的简历入口实际会复用最近的未归档专用会话，并非每点一次必定创建，但仍会让人离开当前对话。本次删除此前端入口与跳转函数，不只是换名字；职业与简历工具均在当前会话运行。原句来源、版本检查、两次人工核对和确定性交付保留。

## 对话管理

- 最近／归档分类，标题搜索（中文、大小写和全角兼容），按更新时间排列。
- 历史条目或当前对话顶部的三点菜单：重命名、归档／恢复、永久删除。
- 菜单复用原生 popover，空白处和 Esc 关闭，键盘箭头导航。
- 重命名弹窗支持 Enter 保存、Esc 取消、trim、1–80 字符与错误重试。运行时允许改名；用户手动设名后不会被第一条消息覆盖。
- 归档只收起，恢复后可以继续。新建只进入空白输入区，不生成多条空记录。
- 手机端当前对话也能使用同一管理菜单。

## 永久删除范围

仅登录的拥有者可删除。运行中、等待运行审批、取消后仍清理，或会话文件正在写入时拒绝删除并说明原因。

真正清除 messages / runs / events / approvals / artifacts 与 conversation 数据；清除本会话 inputs、outputs、所有不可变版本和应用内 local-open 副本。先鉴权和持锁，再核实已解析绝对路径、父目录及整棵目录树无联接／符号链接，最后处理文件和关联表事务。删除持锁期间禁止并发写回，不跟随不可信链接。

独立职业档案、账号级简历草稿和简历历史不属于对话，继续保留；已下载或复制到别处的文件、外部备份不会随之删除。这里的永久删除指应用内不可恢复，不代表磁盘取证级擦除或清除系统／外部备份。

Windows 文件被其他应用占用时，清理可能失败。此时不返回成功，保留对话条目供重试，并说明部分文件可能已经清理；不谎称文件系统和 SQLite 可以一起回滚。

删除选中会话后清除旧 SSE、预览、执行详情和本地选中 ID。服务向其他仍在查看此会话的标签页发送删除信号；旧链接 404 时回空白对话。测试只使用隔离合成数据，不删除用户真实聊天。
