# 功能链路帮助手册（维护版）

> 目标：帮助维护人员快速定位每个功能的**前端入口**、**API 调用**、**后端链路**与**数据表**。
> 约定：前端统一经 `utils/request.ts` 使用 `/api` 前缀调用后端；本项目多处使用本地缓存（`localStorage`）。

---

## 1. 全局入口与基础链路

### 1.1 前端应用入口
- **入口文件**：`frontend/fr/src/main.ts`
- **根组件**：`frontend/fr/src/App.vue`
- **路由配置**：`frontend/fr/src/router/index.ts`

### 1.2 前端请求封装
- **Axios 封装**：`frontend/fr/src/utils/request.ts`
  - 默认 `baseURL`：`/api`（可通过 `VITE_API_BASE_URL` 覆盖）
  - 自动注入 `Authorization: Bearer <token>`

### 1.3 认证与鉴权
- **后端鉴权拦截器**：`backend/ba/src/main/java/com/example/ba/config/AuthInterceptor.java`
- **拦截路径**：`/api/path-plan/**`、`/api/capability/**`、`/api/user/info`、`/api/resume/**`
- **用户上下文**：`backend/ba/src/main/java/com/example/ba/utils/AuthContext.java`

- **`AssistantChatDTO`**（`backend/ba/src/main/java/com/example/ba/dto/AssistantChatDTO.java`）

- **`ReportArchiveRequestDTO`**（`backend/ba/src/main/java/com/example/ba/dto/ReportArchiveRequestDTO.java`）

  - `sortIndex`

- **`LoginVO`**（`backend/ba/src/main/java/com/example/ba/vo/LoginVO.java`）
  - `user`（`User`）、`token`
- **`MbtiQuestionVO`**（`backend/ba/src/main/java/com/example/ba/vo/MbtiQuestionVO.java`）
  - 继承 `MbtiQuestion` 的字段
  - `options`：题目选项列表（`List<MbtiOption>`）

### 15.3 统一返回体
- **`Result<T>`**（`backend/ba/src/main/java/com/example/ba/common/Result.java`）
  - `code`、`msg`、`data`
  - 成功：`code=200`、`msg=success`
  - 失败：`code=500`，或 `Result.error(code, msg)` 自定义错误码

## 16. 附录：异常链路与错误码

### 16.1 异常处理链路（当前实现）
- **无全局异常处理器**（未发现 `@ControllerAdvice` / `@RestControllerAdvice` / `@ExceptionHandler`）。
- **Controller 层 try/catch**：多数接口捕获 `Exception/RuntimeException/Throwable` 并 `Result.error(...)` 返回。
- **业务异常**：以 `RuntimeException` 直接抛出为主。

### 16.2 典型异常来源
- **用户注册/登录**（`UserServiceImpl`）
  - `用户名已存在`、`该手机号已注册`、`用户不存在`、`密码错误`、`账号已被禁用`
- **JSON 处理**（`JsonUtils`）
  - `JSON 序列化失败`、`JSON 反序列化失败`、`JSON 反序列化为对象失败`

### 16.3 常见错误码与说明
- **`401`**：未登录（`AuthInterceptor` 拦截或 Controller 内部判断）
- **`404`**：岗位不存在（`JobController`）
- **`500`**：`Result.error` 默认错误码（通用异常 / 业务异常）

### 16.4 鉴权拦截返回格式
- **拦截器：`AuthInterceptor`**
  - 直接写回 JSON：`{code:401,msg:"未登录",data:null}`
  - HTTP 状态码仍为 200（业务层判定失败）
