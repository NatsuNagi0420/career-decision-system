# 参考资料：这份目录要回答什么

> 这不是"收集资料"目录。每一条文献都必须能指到**一处具体的产品决定或指标**；指不到的，不进索引。

## 一、为什么补文献：四个具体缺口

不是"多读文献更专业"，而是现在有四处地方**拿不出外部依据**，其中两处会被省级结题和试点直接问到：

| # | 缺口 | 现在是什么状态（出处） | 需要文献提供什么 | 不需要什么 |
|---|---|---|---|---|
| 1 | **试点前后测只有一道自造题** | `docs/v2/PILOT_PROTOCOL.md` 观察量表里，"使用后决策是否更清晰""行动是否更明确"各是一道 0–10 自评分，且明写"不做显著性检验" | 2–3 个**在中国大学生样本上验证过**的构念（决策自我效能、决策困难、生涯适应力），可裁到 ≤12 题做前后测；带信度与维度 | "职业规划很重要"这类综述；不做量表改编就当原创量表用 |
| 2 | **比较标准没有出处** | `comparison_criteria` 的标准来自模型与职业目录；"不许把证据数量当适合度"目前只写在代码注释与 `PROJECT_GOAL.md` 里 | 能说明"标准从哪来、哪些维度有实证支撑"的构念（决策困难维度、人-环境匹配、生涯建构） | 再发明一套评分体系；把量表分数直接当推荐排序 |
| 3 | **岗位证据没有等级** | 一条岗位 JD 原文与一份行业报告在比较矩阵里等价使用；`jobs` 表 808 行里 `work_type` 全 `unknown`、无采集日期（`docs/v2/JOB_CATALOGUE_PIPELINE.md` §441–443） | O*NET / ESCO / 《中华人民共和国职业分类大典》的结构颗粒度与更新机制；中国高校毕业生就业的一手统计口径 | 二手"职业前景排行榜"；拿不到原始报告只拿到新闻稿的数字 |
| 4 | **结题材料本身要调研章节** | 第一次季度检查报告「二、研究工作主要进展 →（一）大学生职业发展相关调研」写明用问卷、访谈、案例分析支撑系统设计；周期到 2027.5 | 同上 1–3 的来源，可同时用于结题报告的文献与调研部分 | 与本项目无关的泛教育类文献 |
| 5 | **"大环境变差／这方向会被 AI 冲击"这类句子没有判据**（2026-10-22 加） | 首屏与试点说明里的宏观叙述无官方出处；`笔记/03` 条目[10] 只支撑了"技能会过时"，没支撑"AI 冲击" | **官方统计口径**（调查失业率、分年龄组不含在校生、工资总额口径）＋**暴露度／预期／用量三类数据的性质差别**，用来划定 UI 上能说什么 | 把失业率说成青年失业率；把雇主预期说成事实；把暴露度说成职业判决 |

**一句话**：第 1、2 条决定"试点的结论站不站得住"，第 3 条决定"比较矩阵凭什么可信"，第 4 条是立项书里已经写下的交付物，第 5 条决定"我们能不能对用户说趋势"。五条都不是为了好看。

## 三、来源口径：四级，必须标

| 级别 | 含义 | 能不能当依据 |
|---|---|---|
| **一手** | 读过论文原文 / 官方标准 / 官方统计页面 | 可以，但要写清样本、量表、口径 |
| **仅摘要** | 只读到摘要或出版商页面 | 可以引用结论，**必须**在索引里标"仅摘要" |
| **仅转述** | 只看到新闻稿、公众号、二手报告引用 | **不可**作为依据，只能当线索 |
| **待核** | 拿不到原文也拿不到摘要 | 不进索引正文，记在笔记末尾的"待补"里 |

## 四、引用的三条硬规矩

1. 每条结论后面挂 `[编号]` 指回 `索引.md`，不许写"有研究表明"。
2. 与产品判断冲突时，以 `docs/v2/PROJECT_GOAL.md` 为准——**文献是外部依据，不是需求来源**。尤其：任何量表分数都不许变成"职业适合度"上屏（目标二明令禁止）。
3. 反面证据要留。一条文献如果有相反结果或样本局限，写进"局限/反面证据"，不要只摘支持我们的一句。

## 五、PDF 不建议入 git

实测（**2026-10-22 复量**）：本目录共 **44 个 PDF、合计 110 MB**，整个 `docs/参考资料/` 是 **122 MB**；单篇最大 **27.7 MB**（`02_LLM职业咨询与Agent评测/02_AI个人建议RCT.pdf`），本轮新增最大的是 **17.7 MB**（`06_AI与职业结构/01_WEF未来就业报告2025.pdf`，WEF 主站 403、`www3.weforum.org` 直连超时，只能靠归档站取）。多数期刊也不允许把 PDF 再分发。

**当前整个 `docs/参考资料/` 在 git 里还是未跟踪状态**（`git status` 显示 `?? docs/参考资料/`），所以这一条现在决定的是"第一次提交要不要带上 110 MB 原件"。

建议在 `.gitignore` 加一行，只让笔记、索引与记录进历史：

```gitignore
# 文献原件：版权归出版方，体积大且可再生；索引里保留 DOI/URL 与本地文件名
docs/参考资料/**/*.pdf
```

这一条**还没有加**，需要你确认后我再改（`参考开源项目/` 用的是同一种做法）。若要连抽出的正文文本一起排除，再加一行 `docs/参考资料/工具/原文文本/`——**不建议**：`工具/原文文本/` 只有 12 MB，却是"数字能不能回指原文"的实际依赖。

## 六、维护

- 每条记**抓取日期**。已完成两轮：**2026-10-17**（01/02/03 三专题）与 **2026-10-22**（新增 05/06 两个专题、01 补 [15]–[22]、并关掉 `笔记/03` §C 的 3 项缺口）。量表和职业标准超过 5 年要重核中文版与新版大典。
- **入库前跑一次** `python 工具/audit_numbers.py`：它把记录与笔记里出现的每个数字，拿去 `工具/原文文本/` 与 `工具/网页原件/` 的落盘原文里对账，打行号。**非零不等于有错**（自己测得的字节数、年份、题号都会被打出来），但每一条都要人工判定是"抄错"还是"原文没落盘"。
- **网页正文必须落盘**。本轮的教训：一份 700 行的记录里有 178 个数字回指不到盘上原件，因为它们来自读过但没存的页面——补验时才只能重新联网抓（其中两处原路径已 404，只能靠 Wayback 快照回指）。落盘在 `工具/网页原件/<日期>/`，**失败响应也一起存**（97 字节的空返回正是"取不到"的证据）。
- **口径缺失即判不可用**：数字旁边若没有统计口径（是否含在校生、月/时/年、税前税后、抽样框），降级为线索。本轮实例：某财经稿转述 8 月青年失业率时漏掉"不含在校生"，而它恰好是数值最高的一月。
- **"读过原文"≠"可以上屏"**：分档看设计质量与口径完整度。本轮实例：一件"暴露度→失业"的直接检验是**本科毕业论文**且加权后不显著；一份在线职业咨询元分析报 g=1.65 却纳入了无前对照的设计。
- 撤稿或更正：在索引里标 `⚠ 已撤稿` 并保留行，不删。
- 不追求条数。判据是"每一条都能指到一处产品决定"，指不到的移出索引。
- 本目录与 `参考开源项目/` 性质不同：后者是他人源码快照（已 gitignore），前者是我们自己的判断与题录。
