# 穗奈右眉拆层小样 v01

实际像素编辑中间交付，基准使用任务包内完整 1536×2304 戴眼镜立绘。眉毛层是真实 Alpha 透明 PNG，保留原画布尺寸和坐标；工作底层仅对右侧眉毛原位置做局部修补。ORA 工程内保留原始基准图为隐藏参考层。

- `穗奈_右眉拆层小样.ora`：可编辑 OpenRaster 分层工程（Krita/GIMP 可打开）。
- `右眉_透明图层_1536x2304.png`：独立对齐透明眉毛层。
- `预览_显示右眉.png`：工作底层 + 眉毛层。
- `预览_隐藏右眉.png`：仅显示眉位修补后的工作底层。
- `工作底层_眉位已修补.png`：完整画布，只修补眉位。
- `原始基准_隐藏参考.png`：完整源图副本，ORA 中隐藏。

这是一个真实像素处理小样，不是生成式重绘，也不是 PSD/Cubism 绑定文件。显示/隐藏重组的色差与修补范围请结合验收记录及两张预览核对。
