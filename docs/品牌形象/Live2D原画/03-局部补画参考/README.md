## 怎么判断这张能否用

- 眼镜去除处没有残留灰线、硬边或不自然的皮肤补丁。
- 两只眼睛仍然是原来的眼型、大小、位置与神态，而不是重新画了一双更大的眼睛。
- 脸型、头发、衣领和身体位置与原图一致；不是另一张大致相似的人物立绘。
- 若仅局部可用，只作为补画参考，不拿整张结果覆盖基准。
- 若变化过大就不采用，不为了凑素材反复批量抽图。
