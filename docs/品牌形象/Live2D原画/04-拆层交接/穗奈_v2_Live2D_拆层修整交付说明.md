# 穗奈 v2 Live2D 拆层修整交付说明

## 交付性质

这是**基于原PSD整理的1536×1536可编辑中间稿**，不是任务要求的完整修整成品。它保留源PSD的24个真实像素部件，输出了全画布透明PNG和OpenRaster（ORA）工作稿；明确修正了 `eyewear` 位于 `face` 后方的问题。未用生成式整图替换人物，也未把空白层或复制整图冒充部件。

## 实际完成

- 只读保留原始全身立绘和源PSD，文件放在 `source/`。
- 从PSD读取并导出24个现有图层实际像素。每个PNG为1536×1536 RGBA，按源层坐标放置，不裁边；Alpha保留源图层透明度。
- ORA工作稿内保留24个可见像素层和一个隐藏的、按交接坐标缩放定位的原图参考层。新工程中将眼镜置于脸层上方，重组图像由部件层生成，不含可见整图兜底层。
- 生成白底、深底重组预览、隐藏五官诊断预览，以及前发/手臂粗层平移8px后的缺口诊断图。平移图用于暴露现有遮挡不足，**不是通过移位验收**。
- 导出所有源层名称对应的透明PNG和逐项状态清单。

## 未完成／不能声称完成

- 脸底斑驳、残留区域没有修补；隐藏眼镜/眉眼嘴后的脸底预览会暴露此缺陷。
- 未补画被刘海遮挡的额头/脸侧、头发根部、衣物及四肢遮挡区；前发及手臂移位会露出缺口。
- 眼睛没有达到动作级分层：未补足眼白、虹膜/瞳孔仍是源小像素；没有拆出高光、上下眼睑及闭眼皮肤。
- 嘴部没有拆出唇线、嘴内结构，也未补画口腔。
- 头发仅粗分前发/后发；没有独立主发束、左右侧发；衣物和袖臂手、双腿、鞋仍有合并部件，未进行左右独立细分。
- 眼镜镜腿没有独立拆层；没有完成镜腿与头发交叠检查。
- 没有从1536方形稿重建1440×2560原分辨率工作工程；逆向放大不会恢复细节，因此没有这样处理。

## 工具与验证记录

使用 Python、psd-tools 读取源PSD图层/坐标，Pillow导出透明层及重新合成预览，并按OpenRaster结构写入ORA。脚本在当前环境生成了ORA和PNG；本环境没有启动Krita/GIMP等原生图像编辑器，**未在原生编辑器打开/保存测试ORA**。ZIP结构、图像尺寸、图层文件数及Alpha完整性做了程序校验；这不等同于画师质量验收。

未验证Live2D Cubism导入、网格、绑定、动作、MOC3；未验证原生应用中的显示隐藏行为；未通过脸底、移位遮挡、发丝边缘和手指边缘的美术验收。重组预览只能说明现有层按新层序可合成，不能证明拆层完整或绘画缺陷已修复。
