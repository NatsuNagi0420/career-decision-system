# 交付验收清单

- [ ] 输入原图及PSD保留；本次使用的是v2全身原图，不是旧半身素材。
- [ ] 结果画布、方向命名和坐标有明确记录；不是把正方形画布拉成竖版导致人物变形。
- [ ] 交付工程实际可解析，能读取各层的像素和Alpha，不是平面图改后缀。
- [ ] 实际在所用编辑器中打开结果，并截图或记录显示/隐藏图层；做不到就记未验证。
- [ ] 每个部件文件尺寸相同、位置正确、Alpha真实，不存在空白占位、复制整图或带不透明皮肤的矩形裁片。
- [ ] 使用结果图层重新合成，而不是直接用原图当“重组预览”。
- [ ] 重组时没有仍可见的完整参考图兜底遮掩缺件。
- [ ] 与实际输入原图对照脸型、眼神、五官、发型、发饰、衣物和身体姿势。
- [ ] 眼镜正常显示，头发和镜腿遮挡合理，不与眼球/脸皮肤焊在同一层。
- [ ] 脸底肤色与阴影连续，无明显斑块、眼睛/眉毛/嘴/眼镜残影。
- [ ] 眉毛、虹膜、眼睑、高光等小幅平移后，原位置没有重复部件或未补白洞。
- [ ] 发束和手臂轻微移位后，遮挡区仍有合理内容；不把大幅动作验收混入首版。
- [ ] 轮廓在白、深灰和棋盘测试底上检查；棋盘只用于预览，不能画进部件PNG。
- [ ] 嘴内等新补结构默认被正确遮住，静态闭嘴保留原外观；不宣称已做口型绑定。
- [ ] 以真实部件像素大小说明清晰度，不用画布大小或上采样冒充新增细节。
- [ ] 各部件可复用到后续建模；若有合并或缺件，已明确动作限制和下一步补画需求。
- [ ] 下载ZIP已重新打开或做完整性检查，文件真实存在且内容齐全。
- [ ] 明确哪些是完成、部分完成、未完成、未验证；不把任务包当成成品。
- [ ] 没有承诺已通过Cubism导入、网格、绑定、MOC3或动作验收，除非真的另行执行过。
