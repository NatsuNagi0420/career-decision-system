# 项目现状与这次制作范围

日期：2026-10-19。产品为“青穗集”求职对话助手，陪伴角色为穗奈。核心是画像→岗位→知识缺口与练习→学习/发展路线→简历制作、改进和导出。

## 已核对事实

- 用户确认的全身外观图为1440×2560；See-through及后续修补的实际工作ORA是1536×1536。二者不能直接当相同坐标。
- 工作ORA含25个可见图层及1个隐藏参考层，已复制到本包input/；其中handwear-l/r各自是整条袖子、前臂与手。
- 当前网页有6段可播放原型：待机、招手、倾听、思考、回应、完成。使用二维连续网格与原始手形；可暂停、重播、拖动进度与看近景。
- 当前眨眼主要依靠部件压合，不是重新画好的闭眼眼睑；面部只有原始眼眉嘴，不能靠增加动作名字变成丰富表情。
- 脸底与face_base_repair_patch仍含固定头发/发饰，不能据此独立移动刘海；这是仍待处理的真实问题。
- 当前不是正式Cubism模型，没有穗奈.cmo3或.moc3，也未把原型动作接入真实Agent状态。

## 这轮要交付的具体结果

1. 一套能从当前实际角色直接替换的眼眉嘴与手形，而不是新的整个人物。
2. 干净脸底与去原手的替换臂，解决旧五官/旧手残留。
3. 12组表情合成预览、16只左右手局部接合预览与4种关键姿态接缝检查。
4. 全部53个逻辑部件组的逐项完成状态。P0=40组，P1=13组；原态部件可提取复用，不要求重新生成全部。
5. 标准清单、透明PNG、可编辑源及视觉验收图，打包一次交回。

## 分工

- 用户：把本输入包与总提示词发给Manus，接回一个结果ZIP。
- Manus：读素材、局部补画/图像编辑、分层、同坐标导出、生成真实合成检查图与清单；不要只回计划。
- Codex：独立检查回传素材，接入眼眉嘴与手形切换，按40个配方制作动作时序、触发和打断逻辑，运行浏览器验证。正式Cubism建模另需在编辑器中制作并检查模型，不把二维原型当MOC3。

## 预算与一致性取舍

直接生成40张整人物容易反复换脸、换手臂长度，也难拆层复用。使用8种手形（各左右）＋6类眼型（各左右）＋6类眉型（各左右）＋7嘴型＋脸底/替换臂和可选道具，支撑40个场景配方。动作中抬手、点头、节拍和视线由代码完成；只有新轮廓、掌面与口腔内容需要画。

动作和表情统一为温柔、有精神、成年人的自然交流；不把求职进度演成情绪好感惩罚，不用持续夸张开心/沮丧妨碍读简历。

本轮允许同一任务内部先P0后P1，允许记录少量确实做不到的P1；不要求用户反复补传原文件。若遇到某个具体源文件无法解析，先用已对齐PNG推进可完成部分，并明确缺失，不能因此只写一段拒绝说明。
