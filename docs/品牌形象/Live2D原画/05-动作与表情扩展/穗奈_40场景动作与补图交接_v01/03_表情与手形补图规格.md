# 表情、手形与补画清单

## 先完成什么

顺序为：干净可换五官的脸底F01 → 去掉旧手的原臂ARM01_L/R → 眼眉嘴部件 → 左右手形 → 合成表情/手部接缝预览 → 可选道具。P0共40个逻辑部件组，P1共13个；其中原态眼眉嘴、原手和衣袖可以提取复用。**这是53个逻辑组，不是53张新整图，也不是53个源图层。**

每一组的ID、优先级、路径、锚点与要求以catalog/assets_requested.json为机器清单。拆层源工程中的叶图层可以多于一组，交付时逐项登记真实路径。

## 眼睛：6类，每类左右独立

| ID | 名称 | 优先级 | 要求 |
| --- | --- | --- | --- |
| V01 | 原态睁眼 | P0 | 沿用当前睁眼外观，保留棕色虹膜与高光。 |
| V02 | 柔和眼 | P0 | 上眼睑轻落，目光柔和但仍能看清瞳孔。 |
| V03 | 半睑专注眼 | P0 | 上眼睑适当压低，用于专注与思考；不是把整只眼竖向压扁。 |
| V04 | 自然闭眼 | P0 | 新画闭合眼睑和睫毛轮廓，保留眼窝的体积。 |
| V05 | 开心笑眼 | P0 | 弧线自然向上弯的笑眼，区别于自然闭眼。 |
| V06 | 轻度睁大眼 | P1 | 眼睑略张开，虹膜大小稳定，避免惊恐瞪眼。 |

- 开眼源组包含：眼白、虹膜（高光可与虹膜同组）、上睫毛/眼睑、下眼睑；不能只沿用“整眼压扁”。眼睑要能遮住虹膜，不露皮肤缝。
- 闭眼/笑眼源组只交实际需要的闭合眼睑睫毛；眼白/虹膜在该变体不显示，不必输出伪空白PNG凑层数。
- 为先接入当前二维渲染，每侧每类另导出一个完整眼部合成透明PNG，例如V02_L.png；它会整体替换同侧旧眼部。源工程仍必须保留开眼的眼白、虹膜、眼睑，供后续正式绑定。
- 原棕色瞳孔、眼睛间距、眼角位置不变；额外高光不能过曝，不能把成年人物改成大眼幼态脸。

## 手形：8类，每类左右分别画

| ID | 手形 | 优先级 | 要求 |
| --- | --- | --- | --- |
| H01 | 放松自然手 | P0 | 沿用原图手形，提取手腕以下并补短接缝，不重画成长手指。 |
| H02 | 正面招手掌 | P0 | 五指自然张开，拇指外展，指长有层次；掌心向观众，不使用原图手背假装挥手掌。 |
| H03 | 自然托示掌 | P0 | 掌心可见并微凹，四指放松舒展，拇指与食指有正常分离；用于伸手介绍、展示。 |
| H04 | 食指提示手 | P0 | 仅食指自然伸出，其余三指弯曲、拇指贴靠；不是数根直棍或多指畸形。 |
| H05 | 脸侧思考手 | P0 | 食指与中指自然略弯，其他手指收拢，接触侧轮廓平顺；只画手，不把下巴或脸颊烘焙进去。 |
| H06 | 轻握鼓励拳 | P0 | 自然轻握拳、拇指压在食指外侧；不是战斗用力握拳，不夹带道具。 |
| H07 | 认可拇指手 | P1 | 拇指明确竖起，四指自然收握；轮廓在网页缩小后仍可辨认。 |
| H08 | 自然握笔手 | P1 | 拇指、食指、中指形成合理握笔空间；笔独立透明层，握持接触关系另给预览。 |

- 总计16个左右手逻辑组，其中H01_L/R来自原图提取；不要把角色左手镜像后不检查就当右手。
- 手形在**原图垂臂时的腕部坐标**制作，掌轴沿原手腕延伸，程序负责将整个手臂抬到脸侧或肩侧。不能给H05直接画一只悬在脸旁且没有注册坐标的手。
- “托示掌”指可用于介绍时的自然掌部形态；不是把手画在最终抬手位置。每类要附一个按目标姿态旋转后的接缝示例，方向不自然时修图而不是强行旋转180度。
- 保留与原画一致的肤色、指甲、关节、侧面轮廓与阴影。看得到的五根手指应有合理归属；握拳时被遮住的手指不要求全部外露。
- 掌长、指长、腕粗与原手相容。不能为了更显眼把手画大一倍，不能靠巨大的白色皮肤块盖住前臂。
- 从指尖到掌心的表面改变需要新画；只改平移、抬臂、弯肘、点头、歪头、眼神通常先由代码变形解决，不让Manus重画整个人。

## 接缝和遮挡修补

F01替换face和face_base_repair_patch，不叠在旧五官之上。提供隐藏全部眼眉嘴、眼镜、刘海、发饰后的脸底检查图，明确标出仍未处理的区域；不准拿带眼睛的整脸挡住残留。当前脸底仍含固定头发，这是已知遗留，不要声称源文件已经是干净脸底。

ARM01_L/R保留原衣袖与前臂，只去掉原手并补齐腕部重叠皮肤。替换手与原臂接合后不能看到旧手的指头、肤色双边或裂口。上臂、前臂进一步精细拆层不是本轮PNG替换的硬前提；确实需要新增遮挡补全时独立命名，记录改了哪里。

## 可选P1素材

- X01：低饱和淡腮红，独立透明层，不连皮肤。
- P01：无文字、无品牌细笔，透明层，能与H08形成真实夹持。
- P02：无文字便签，透明层，由另一只H03承托。简历/岗位内容由网页排字，不画进图中。
- 道具无法制作时如实列未完成，A10/A35保持待制作；不要用漂浮的笔或错误的握持交差。

## 画风与质量

锁定1440×2560原画中的棕发、棕瞳、细圆框眼镜、麦穗发饰、淡蓝紫开衫、白内搭和深色裙装。以input中1440×2560图锁外观，以1536工作文件锁位置。所有示意放大图只是参考，不代表源部件新增了像素细节。

当前脸部有效像素有限，这批优先解决神态、手势和接缝；以后若做大幅面部特写，再统一升级高分辨率源工程，不能只把当前部件插值放大后宣称高清精修。
