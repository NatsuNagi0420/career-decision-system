# 你怎么发给Manus

1. 上传本目录旁边的“穗奈_40场景动作与补图交接_v01.zip”，只上传这一个文件即可。
2. 复制“给Manus_一段总提示词.txt”中的整段正文发送；不用再另传基准图、PSD、脸底ZIP或逐份文档，这些必要输入已装入同一个包。
3. Manus做好后下载它返回的suinai_extensions_v01.zip，放到本项目“docs/品牌形象/Live2D原画/05-动作与表情扩展/回传素材/”目录，再让Codex检查。

本包已经规划40个场景动作，但本轮没有把40个全部制作成可播放动画。眼眉嘴/手形合格后，Codex再接入表情和换手、制作动作时序。不能只看“它回复说完成”就跳过验收。

如果它确实做不完，接收已完成的素材与逐项清单，再据此补缺；不要为了追求一句“全完成”丢掉已有成果。已有的6段预览仍可使用。
