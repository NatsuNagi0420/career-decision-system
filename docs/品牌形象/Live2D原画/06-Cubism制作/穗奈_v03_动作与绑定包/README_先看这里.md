## 真正模型还缺哪些工作

**没有交付 `.cmo3` 或 `.moc3`。** 当前机器未找到 Cubism 安装项或穗奈原生模型，当前会话也没有原生编辑器 GUI 操作面；不拿官方 Haru 示例替代穗奈。

下一阶段需要真正进入 Cubism：

1. 导入 PSD 候选，核对默认画面、隐藏层、剪贴/透明信息。若编辑器未保留剪贴关系，重新给完整瞳孔指定眼部遮罩，不能把修补底图打开来遮洞。
2. 做脸部与眼睑、眉嘴、躯干、双臂的 ArtMesh；细修肩缝、肘部与腕部。PSD 的“整臂六变体”是一种连续源图组织方式，并非已经完成的原生绑定。
3. 按 `parameters.json` 创建 25 个参数并制作关键形。手形参数用离散不透明度切换；双臂变体复用父级形变，避免分开刚性转动手掌而出现三角裂缝。
4. 眼球两侧共用同一目标；V03 的内聚偏瞳不叠加使用。做真实眼睑中间形，不能把当前压合预演当作眼睑网格终稿。
5. 头部小幅俯仰、侧倾时，脸底内固定头发与前后发保持整体衔接。本版没有承诺大角度左右转脸；那需要额外的遮挡补画与绑定。
6. 保存原创 `Suinai.cmo3`，导出 `Suinai.moc3`、纹理图集与 `Suinai.model3.json`；再将动作文件挂到真正的穗奈运行时上。现有官方对照页面仍是 Haru。
7. 用真实模型验证全部动作，尤其左右肘弯到 ±165°、腕部 ±16°、手形切换、眼睛开合与被异常状态打断；检查拉花、穿脸、遮挡、露洞和结束残留。

**模型阶段的完成标准不是“文件有了”，而是原创模型能被真实 Core 加载，参数确实驱动对应网格，40 场景在该模型上实际播放验收。**
