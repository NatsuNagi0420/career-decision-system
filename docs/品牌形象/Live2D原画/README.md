## 这张图的建议要求

以下是本项目的制作建议，不是 Live2D 官方强制画风或尺寸：

- **构图**：正面平视，头摆正，身体不扭转。画面从完整头顶到大腿上部，左右手臂、手部尽量完整入画，四周留少量空白。第一版动画重点仍是面部和上半身，不要求走路或复杂手势。
- **姿势**：肩膀放松，脖颈与肩线自然；双臂自然下垂，与身体略留间隙，不交叉、不拿道具、不遮挡脸和衣领。
- **表情**：双眼自然睁开、看向前方、闭嘴轻微微笑。不要用大笑、闭眼或夸张表情当基础图。
- **画风**：清晰的二次元立绘，正常人物比例，非 Q 版、非像素、非点阵。线条干净，色块和阴影清楚；眼镜反光不挡住眼睛。
- **画面**：仅一个人物，不要九宫格、设定集拼图、分解图、文字、水印或复杂背景。透明背景最好；工具不支持真透明时，纯浅色背景也可以，不要要求模型把棋盘格画出来。
- **清晰度**：优先保存工具提供的最高原始分辨率。可把竖版约 2:3、2048×3072 或更高作为目标；如果只能输出较小尺寸，先保留原图，不要简单拉伸后当成新增细节。

不要为了这些建议反复重画一张已经满意的图。收到候选后，先检查外观和可制作性，再决定是否需要局部修改。
