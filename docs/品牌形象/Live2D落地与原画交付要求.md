# 穗奈 Live2D：先跑通交互，再制作正式模型

更新时间：2026-10-18。

## 当前已做和没有做

- 独立预览：`http://127.0.0.1:5174/?preview=live2d`，不登录，不连接业务 API，不调用大模型。
- 使用官方 Haru 模型作技术占位。它不是穗奈，也不是本项目原创建模。
- 真正加载 MOC3、贴图、物理和姿势文件，在 WebGL 中渲染网格；不是移动一张 PNG。
- 6 种交互状态：待机、倾听、思考、解释、完成、关切。状态以真实模型参数缓动呈现。
- 新制作 3 段非循环参数动作：点头、侧头倾听、完成回应。只使用模型确实存在的参数；缺少参数时禁用动作。
- 支持自然眨眼、呼吸、发丝/衣物物理、局部视线跟随、暂停、离屏和后台暂停、系统减少动态效果、加载失败重试。
- 口型滑块只是手动测试，不是音频同步。文字输出不会自动假装正在说话。
- 正式穗奈原画、拆图、原创网格与变形器绑定、可编辑 `.cmo3` 工程尚未完成。
- 目前没有将官方示例替换进正式 Agent 桌面。不要把技术占位误当作已上线的新穗奈。

## 原画到位前，能推进什么

1. 调整交互状态和动作幅度，验证动作是否打断用户阅读。
2. 确认模型缺少哪些参数，不用错误标签冒充动作。
3. 继续制作可复用参数短动作；人物外观改掉后仍需按新模型重新检查范围和接缝。
4. 准备新模型的参数命名、文件交付与验收清单。

不能先完成一份和原画无关的“正式绑定”。网格、变形器、眼口结构、头发物理和关节遮挡都依赖实际原画。正式建模需要在 Cubism Editor 中逐项制作并可视检查；SDK 运行控制不等于原画绑定，也不能承诺靠一段程序从任意 PNG 自动导出高质量 MOC3。

## 给生图与拆图阶段的要求

### 先定一张真正满意的基准图

- 高清二次元半身，正面或轻微侧向，肩膀放松，双手尽量不遮住脸和衣领。
- 保留穗奈已确认的识别特征。不要同时更换发型、眼镜、服装和脸型。
- 建议半身原图高度约 3000–4000 像素，这是制作建议，不是 SDK 强制要求。
- 无文字、无水印、无复杂背景；透明背景最佳，但头发不能被粗糙抠掉。
- 原图、后续表情和姿势必须来自同一个人物设计。多张独立生成的“差不多同一个人”并不能直接拼成稳定模型。

### 正式建模需要有遮挡补全的分层素材

一张扁平 PNG 可以用来定外观，但不是完整建模源文件。可以交付分层 PSD，或所有图层同尺寸、同坐标、透明背景的 PNG 套件。不要独立裁切成不同画布。

建议图层：
- 头发：后发、左右侧发、刘海分束，发饰单独保留。
- 头部：脸底、耳朵、颈部；头发后面的脸和颈部要补全。
- 左右眼：眼白、虹膜/瞳孔、上/下眼睑或睫毛、高光；眉毛左右分开。
- 嘴巴：嘴内、上/下唇或轮廓、牙齿、舌头，按实际画风取舍。
- 眼镜：镜框和必要的镜片反光，不和眼睛、脸焊在同一层。
- 身体：躯干、衣领/外套、左右上臂、前臂、手部；手臂后方的躯干要补全。
- 道具：纸张、文件夹、笔独立。第一版先不做复杂拿取与交接动作。

补全不是简单抠图：例如转头露出的脸侧、刘海后面的额头、抬手露出的衣服，原图中没有的信息需要补画。

## 目标参数与第一版动作范围

优先采用 Cubism 通用命名：`ParamAngleX/Y/Z`、`ParamEyeLOpen/ROpen`、`ParamEyeBallX/Y`、`ParamBrowLY/RY`、`ParamMouthForm`、`ParamMouthOpenY`、`ParamBodyAngleX/Y/Z`、`ParamBreath`。

第一版只要求半身：眨眼、呼吸、小幅转头/歪头、视线、微笑/思考/关切、点头。头发和衣物做轻微物理。大角度转身、复杂手势、走路、精确音素口型不在首批范围。

正式交付包括：可编辑建模工程 `.cmo3`；模型 `.moc3`；入口 `.model3.json`；贴图；物理 `.physics3.json`；所需表情 `.exp3.json`；短动作 `.motion3.json`；必要的姿势文件。仅拿到 PSD 不能在网页里当 Live2D 成品播放。

## 代码与构建

- `web/src/character/live2d.ts`：共享状态契约和事件优先级。错误 > 待确认 > 处理中 > 明确完成 > 未发送输入 > 回复 > 待机。
- `web/scripts/live2d-runtime.mjs`：薄适配器，调用固定版本的官方框架，不修改官方实现。
- `web/scripts/build-live2d.mjs`：从本地源码构建 IIFE 运行时并生成 3 段动作；不在构建时联网。
- `web/src/components/Live2DCharacter.tsx`：异步加载与资源生命周期。
- `web/src/components/Live2DStudio.tsx`：仅本地演示，模拟结果明确标注。
- `web/vendor/live2d/framework/`：未修改的官方 SDK 框架源码，保留原版权。
- `web/public/live2d/`：本地运行时、Core、模型、动作、着色器及许可记录。

执行 `npm run live2d:build` 重新构建运行时。正式 `npm run build` 已包括该步骤。只修改试映室界面不需要重建运行时；修改 SDK 适配器或共享状态参数后要重建并刷新页面。
