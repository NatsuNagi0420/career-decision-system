# 二次元像素风参考与穗奈中模改造方案

更新：2026-10-18

## 先说结论

当前穗奈的问题不只是原生网格大小，而是绘制方式。现在的角色主要由代码中的多边形、折线和色块组合生成，优点是状态切换容易、无需外部素材，缺点是角色比例、像素簇、轮廓节奏和动作连贯性很难达到成熟二次元像素作品的水平。

下一版把职责拆开：

- Pixelorama 负责手工绘制角色、轮廓、表情、衣服、道具和关键帧。
- 前端代码负责状态机、动作选择、播放速度、暂停、减少动态效果和业务状态映射。
- Canvas 只负责显示导出的 PNG 帧或 sprite sheet，不再用大量几何代码重新生成脸和肩颈。

这样可以继续保留 Agent 的交互能力，同时让角色素材按真正的像素画流程打磨。

## 参考方向

### 1. Eastward：像素簇、材质和画面密度

Eastward 官方将自己的视觉描述为受 90 年代日本动画启发的丰富像素作品，并结合现代 3D 光照。它适合作为“中模”参考：轮廓先读清楚，再通过成组的明暗像素表现头发、衣服和环境材质。

借鉴点：

- 先做清楚的外轮廓，再填材质像素簇。
- 头发不是一整块渐变，而是分成几束有方向的色块。
- 暗部不全部使用同一个黑色，轮廓色要跟随材料和背景变化。
- 角色放在环境里仍能一眼读出脸、头发、衣服和动作。

### 2. Coffee Talk：二次元人物、陪伴感和稳定表演

Coffee Talk 官方介绍明确提到 90 年代动画、经典像素冒险游戏和舒缓氛围，这比单纯追求 RPG 战斗精度更适合穗奈。它适合参考“陪伴型角色”如何通过脸部、姿态、配色和界面共同传达情绪。

借鉴点：

- 穗奈的脸要优先保证眼神、嘴形和眉峰的可读性。
- 服装细节服务于性格和识别度，不把肩颈、袖子和领口画成复杂噪声。
- 表情变化应该改变眼睑、视线、眉毛和嘴角的关系，而不只是换一张嘴。
- 背景、面板和角色色彩要共同营造“愿意继续说话”的感觉。

### 3. NEEDY STREAMER OVERLOAD：交互表演和 UI 角色感

NEEDY STREAMER OVERLOAD 的官方页面把重点放在角色陪伴、每日引导、消息回应和多结局体验上。它不应该被当成穗奈的纯像素画技术参考，因为它的核心优势更多是角色表演、界面节奏和情绪反馈。

借鉴点：

- 每个动作都要回答“穗奈现在在和用户建立什么关系”。
- 倾听、思考、鼓励、提醒要有不同的身体重心和停顿，而不是只换标签。
- UI 的反馈节奏应当给角色留出表演空间，避免角色只像一个装饰头像。

### 4. Pixelorama 与 Aseprite 工作流：图层、关键帧和洋葱皮

Pixelorama 官方文档提供图层、时间线、帧和洋葱皮工作流，适合当前项目的免费素材制作方向。Aseprite 官方文档也把角色动画组织为图层、帧、cel、动画标签和洋葱皮。我们可以借鉴这种生产方式，即使最终使用 Pixelorama，也要保持素材结构清楚。

穗奈建议使用这些图层：

1. `outline`：外轮廓和局部轮廓修正。
2. `hair-back`：后发和发梢。
3. `body-base`：身体、开衫和白色衣身。
4. `neck-face`：脖子、脸和耳朵。
5. `hair-front`：刘海、麦穗发夹和脸侧发束。
6. `face`：眉毛、眼睛、眼镜、鼻子和嘴。
7. `hands-props`：手、手账、笔和资料卡。
8. `effects`：眨眼高光、轻微呼吸辅助像素和状态提示。

## 当前穗奈需要改变的地方

### 脸部

当前脸部轮廓的问题是局部修补过多，导致下巴、颈部和头发互相覆盖。下一版先画一张稳定的中性脸，再复制出放松、倾听、思考、鼓励和提醒五种表情。

验收标准：在 2 倍放大和实际小窗尺寸下，眼睛、眼镜、嘴和下巴都能被快速读出；下巴不依靠一条横线或深色缝隙表达形状。

### 肩颈

当前肩颈的问题不是单纯肩宽，而是肩峰、脖根、衣领和头发底边没有被作为一个整体设计。下一版先用简化骨架确定颈部、锁骨、肩线和袖口，再填颜色和纹理。

验收标准：肩膀处于放松状态，衣领能自然包住脖根，头发落在肩膀前后关系清楚；动作帧中肩线不会突然抬高或塌陷。

### 手部

手部要先做三个高频动作的清晰关键帧：捧手账、脸侧倾听、递出资料。每个动作先保证手掌方向和手腕位置，再补手指像素。当前同时画六种动作和八种神态，导致局部细节被摊薄，下一版会减少首批动作数量。

### 动画

动画先做 4 帧待机和 4 帧倾听：胸口只做约 1 个原生像素的呼吸变化，头发和衣服做轻微延迟，眨眼使用独立两帧。AdamCYounis 的 idle animation 教程也把胸部、手臂、头发和次级运动拆开处理；Pixelorama 和 Aseprite 的洋葱皮功能适合用来检查这些变化是否连贯。

## 下一版中模规格

- 单帧目标：192×256 原生像素，继续保持当前页面显示尺寸。
- 首批只做：中性待机、倾听、鼓励、思考四种状态。
- 每个状态先做 1 张静帧，再做 4 帧小循环。
- 调色板控制在约 24–32 色，按皮肤、头发、服装、玻璃、金属和麦穗分组。
- 轮廓使用深色彩色轮廓，减少大面积近黑色连续带。
- 先完成角色模型表，再扩展确认、写作、对照和收纳动作。
- 代码保留现有状态映射和测试边界，素材层替换为可编辑 PNG 帧或 sprite sheet。
