## 已做什么

- 构图坐标仍为 96×128，运行时使用 192×256 原生网格；每个构图格拆为 2×2 原生像素，固定色板，透明背景，页面显示尺寸不变。
- 保留栗棕发、琥珀眼睛、银色圆框眼镜、画面右侧麦穗发夹和浅蓝开衫。
- 六个动作：拿手账、专注倾听、记笔记、并列对照、请用户确认、收好成果。
- 两种渲染器：方块像素、彩色圆点，共用一份角色和动作数据。
- 轻微呼吸、半闭—闭眼—睁眼、短暂侧视、点头、手腕和笔尖移动、纸卡抬起与纸页收纳。
- 缩小头部在半身中的占比，重画肩膀、弯肘、袖口和手腕。倾听时手指到脸侧，确认时侧向摊掌，避免竖掌像“停止”。
- 八种神态：放松、倾听、思考、解释、鼓励、开心、关切、提醒。动作自动选择默认神态，试映室可单独覆盖。
- 8 帧/秒、48 帧的确定性循环，可暂停、逐帧检查。
- 离屏、页面进入后台、系统设置减少动态或桌面关闭界面动画时暂停自动动画。
- 聊天头像独立裁切到头部并默认静止；登录页人物也保持静止，避免干扰输入。
- 显示方式使用浏览器本地偏好，不改变账号资料，不请求模型。

这是一份**代码绘制的像素原型，不是最终精修像素美术**，也不是对旧立绘做缩图、马赛克或图片滤镜。小窗里的面部细节和动作衔接仍需继续做审美验收，测试通过不等于美术品质通过。旧 PNG/WebP 全部保留，未覆盖。

## 查看与操作

- 本地前端在 5174 端口运行时，打开 `http://127.0.0.1:5174/?preview=suinai`。
- 不必登录即可查看试映室；该页面不挂载业务应用，不请求业务 API。
- 已登录：桌面陪伴小窗里点「角色试映室」，或账号菜单里点「穗奈角色试映室」。
- 未登录：登录页底部点「看看像素穗奈」。
- 支持显示方式切换、六个动作按钮、八种神态、播放/暂停和逐帧滑块。
- 系统开启减少动态效果时，自动播放不可用，但仍能用滑块检查静帧。

## 真实状态与演示的边界

| 位置 / 状态 | 当前动作 | 不应推断 |
| --- | --- | --- |
| 桌面空闲 | 拿手账 | 不说明用户的能力或求职进度 |
| 消息框有未发送内容 | 专注倾听，清空即回待机 | 仅根据本地输入框是否为空，不分析内容、不触发 API |
| 真实任务处理中 | 记笔记 | 不代表模型处理的具体百分比 |
| 等待用户确认 | 请你确认，优先于处理中 | 不代表已经写入资料 |
| 时间线头像 | 沿用消息表情，使用静态头部裁切 | 开心不等于保存成功 |
| 试映室「收好成果」 | 纸页放入文件夹的本地动作演示 | **没有接到任何真实保存成功事件** |
| 试映室讲解时的嘴形变化 | 普通周期关键帧 | 不是语音合成或音画同步 |

当前没有为每个业务结果实现完整状态机。将来若接入「收好成果」，须监听真实成功响应，不能仅凭切换页面或生成草稿来触发。

## 验收

在项目根目录执行：

```powershell
npm --prefix web run typecheck
npm --prefix web test
npm --prefix web run build
node web/e2e/suinai-sprite.mjs http://127.0.0.1:5174
node web/e2e/desktop-theme.mjs http://127.0.0.1:5174
```

角色验收输出：`logs/suinai-face-20261018/`；前一轮 `logs/suinai-presence-20261018/` 保留作历史对照。使用 Google Chrome 的 Playwright 通道。

角色脚本使用本地页面及业务 API 替身，不写真实资料、不调用语言模型或出图 API。原有桌面验收也必须保留通过。

## 后续优先级

1. 先在试映室对照 v0.4 素材稿和 v0.3 代码稿，检查脸型、眼镜、发梢、下巴、肩颈和动作是否符合期待。
2. 确定方块像素还是点阵作为默认；当前默认是方块像素，两者均可切换。
3. 优先完善状态切换的过渡和小窗可读性；真实完成动作仅在真实成功事件后触发，不先堆几十个姿势。
4. 仅在确有新交互时再做行走、转身或桌面移动。不能只给半身图位移就称为行走动画。
5. 暂不做换装、完整房间 CG、Live2D、语音同步、压力值和依赖机制。


## v0.3 下颌与密网格精修记录

- 通过 192×256 原生网格重绘轮廓，显示大小仍保持原来的 288×384 角色画布，不用放大图片冒充精细化。

- 这仍是代码像素原型，2×原生密度解决了轮廓取样空间问题，但最终角色审美仍需继续看小窗尺寸下的脸部灵性、手部可读性和动作节奏。
