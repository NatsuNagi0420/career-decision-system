## 0. 怎么用

1. 上传现有默认微笑图作为**身份与画法参考**；上传现有正面图作为**服装比例参考**。不要上传游戏角色截图作为角色参考。
2. 先只做 A1：粘贴「共同要求」+「A1 动作」+「负面约束」。
3. 第一张通过后，把定稿 A1 作为后续图片的**编辑目标**，原微笑图仍为**身份参考**；保留画布、构图和人物定位，只变动作。
4. 一次只做一个动作，按 A2–A6 分开生成。不让模型输出带排版和标签的整张动作表。
5. 检查眼镜、发夹、手部和透明通道；如工具不能输出真透明，先明确交付纯色背景待去背图，不把它命名成透明图。

推荐参考文件：

- 身份参考：`docs/品牌形象/BgSub_默认微笑.png`
- 服装参考：`docs/品牌形象/BgSub_穗奈正面图.png`

## 1. 共同要求

```text
为原创求职成长桌面「青穗集」制作角色穗奈的透明半身动作素材。

输入图片的角色必须是唯一身份来源：第一张用于脸型、发色、眼睛、眼镜、发夹和线稿画法；第二张只补充服装结构与身体比例，不改变第一张的脸。

角色是温和、细致、清醒的成年大学生同伴，不是教师、招聘官、偶像或全知导师。保留栗棕中长发、琥珀色眼睛、细银色圆框眼镜、麦穗发夹。发夹位于正面参考中相同的一侧，正面观看时在画面右侧，禁止镜像换边。保留浅天蓝开衫和象牙白内搭，沿用参考中的领口、袖口和扣子结构。

延续原参考的清晰二维动漫线稿与简洁赛璐璐色块，不改变年龄感、头身比例、脸型、发型长度或服装。不新增复杂装饰；不为了浅紫桌面把头发或衣服染成紫色。人物不是像素画；复古感由产品窗口承担。

单人，正面到轻微三分之二角度的半身构图。自然、平等的交流视线。头顶、眼镜、发夹、双手和本次动作道具完整可见，身体下缘统一做半身裁切。面部、手和道具不相互遮挡。

适合放入宽约276像素的陪伴窗口，轮廓和动作在缩小时仍能辨识；道具不堆叠。纯粹的独立角色素材，不绘制桌面界面。

输出一张竖版RGBA PNG，真正透明背景，不绘制棋盘格、底色、窗口、按钮、文案或水印。目标1024×1280；不支持该尺寸时保持比例使用支持的竖版画布，后续统一装入目标画布，不拉伸角色。主体四周保留透明安全边距。
```

后续动作还需追加：

```text
这次是编辑同一张已定稿的A1角色图，不是重新设计人物。保持原画布大小、头部位置、脸部尺寸、眼线高度、画风、服装、发夹侧别、光照方向和透明背景不变。仅修改下面明确指定的手臂、道具与必要表情，其他部分尽量保留。
```

## 2. 六个动作分开制作

### A1 默认陪伴 / `suinai-journal-v2.png`

```text
动作：穗奈在胸口偏下的位置拿着一本打开的小手账，另一手握笔停在页面上方，抬眼看向用户，嘴角轻微微笑，像正在和同伴一起整理经历。手账为简洁青绿封面，带少量浅麦色索引，无字无Logo。姿势自然，人物居中，脸和两只手都清楚可见。不要举书挡脸，不要伸笔指向用户，不做庆祝动作。
```

### A2 专注倾听 / `suinai-listen-v2.png`

```text
动作：在同一半身站位中略微向交流对象倾身，双手自然扶住合拢的同一本手账，肩膀放松，目光专注，嘴自然闭合；只通过轻微眉眼和姿态表达认真倾听。不是惊讶、委屈、撒娇或求关注。保留既定头部大小和定位，不把整个人放大成近景。
```

### A3 整理与思考 / `suinai-think-v2.png`

```text
动作：在同一位置低头轻看打开的同一本手账，用握笔的手对照两张夹在页边的空白索引便签，眉眼轻微思考，神态从容。身体动作比眼睛变化更清楚，但头部不大幅移动。不要托着整张脸，不要夸张问号、汗滴、光效、进度条或数字。
```

### A4 对照与讲解 / `suinai-compare-v2.png`

```text
动作：双手在胸前并列展示两张相同大小的简洁资料卡，左右卡片保持平等、不做好坏对比，卡片只有少量抽象横线或色块，没有可读文字和数字。穗奈面向用户温和讲解，两手与两张卡清楚可见，脸不被挡住。不要指向唯一正确答案，不要胜负符号、百分比、招聘公司Logo或录用暗示。
```

### A5 请你确认 / `suinai-review-v2.png`

```text
动作：一只手将一张无字资料页自然递向用户，另一只手轻扶合拢的手账，表情认真且平等，像邀请对方检查内容。纸页保持在胸口下方，不遮挡脸和眼镜。不要盖章、打完成勾、举起奖状，不做警告或责备姿态。动作含义是等待用户确认，不是已经保存。
```

### A6 已保存成果 / `suinai-filed-v2.png`

```text
动作：一只手扶着简洁浅麦色文件夹，另一只手把一张无字纸页放进去，表情是轻松、安心的微笑，表示一份资料已经妥善保存。文件夹在胸口下方，双手和纸页边缘清楚，没有多余道具。不要夸张欢呼、彩带、奖杯、合格证、offer、薪资或就业成功暗示。
```

## 3. 通用负面约束

```text
不同人物或换脸，眼镜消失、变形或不对称，发夹换边或缺失，发色瞳色改变，衣服结构改变，头部大小漂移，画布裁断头顶、手或道具；
儿童化或玩偶脸，性感化服装，暧昧姿势，夸张身体比例；
真人、3D、厚涂、写实皮肤、过量光泽、像素化滤镜、模仿现有游戏角色或特定画师；
多余人物，融合手指，多余肢体，笔穿过手掌，纸张穿过手臂，道具遮脸；
背景场景，桌面UI，文字，乱码，水印，品牌Logo，录用证书，能力分数，百分比，压力值，好感度；
白色外描边，黑底，画在图片里的透明棋盘，夸张光晕，模糊边缘。
```

注意：**不要**把「半身像、近景」加入本批动作的通用负面词；这一批本来就需要统一半身素材。全身三视图暂不重做。

## 4. 单点返修提示词

每次只改一个问题，避免一次修改多项又导致身份漂移。

### 修正发夹

```text
只修正麦穗发夹的位置与方向，使其完全跟随身份参考，正面观看时位于画面右侧。保持脸、眼镜、发型、姿势、衣服、画布和透明背景不变。不要镜像整张图片。
```

### 修正手部

```text
只修正本次动作中不自然的手部和握持关系。手指结构自然，笔或纸张与手掌的接触关系可信；保持脸、发夹、服装、人物位置和画布不变，不增加道具或改变动作含义。
```

### 透明边缘修正

```text
只移除人物外部的白边、背景色残留或伪透明棋盘，输出真实透明通道。保留原人物轮廓、头发细节、眼镜透明区域和手部，不重新绘制角色，不改变画布大小与定位。
```

## 5. 暂不做的提示词

先不制作换装、房间CG、Q版套图、Live2D拆件或整套逐帧动画。完成A1并验证小窗呈现，才能扩大这一批；不能用图片数量代替一致性验收。
