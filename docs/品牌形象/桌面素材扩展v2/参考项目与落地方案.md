# 穗奈像素角色参考项目与落地方案

更新：2026-10-18。

## 已下载的参考项目

### Godot Pixel Cutout Rig

本地目录：`D:\IDE\references\godot-pixel-cutout-rig`

项目地址：`https://github.com/haingt-dev/godot-pixel-cutout-rig`

借鉴：

- 每个部件都是透明 PNG，关节 pivot 放在素材中心。
- 部件使用偶数尺寸，避免半像素接缝。
- 远侧部件放在身体后面，近侧部件放在身体前面，遮挡关系由树结构表达。
- 像素角色使用刚性部件旋转，避免网格变形导致像素闪烁。
- 用 joint-stress 检查极端角度下的接缝。

舍弃：

- 它的输入契约是纯侧面角色，适合行走，不适合穗奈的正面三分之二陪伴构图。
- 它的示例角色只是技术占位，不能作为穗奈的美术参考。
- 手和表情不应该完全绑定在前臂旋转上，穗奈需要单独的手部和表情关键帧。

### Modular Char

本地目录：`D:\IDE\references\godot-modular-char`

项目地址：`https://github.com/godot-x/modular-char`

借鉴：

- 用 Marker2D socket 放置头部、嘴、披风、武器等部件，避免坐标散落在代码中。
- 部件可以运行时替换，动画逻辑不和具体素材文件耦合。
- 动画状态、循环、过渡和运行时换装有清晰接口。

舍弃：

- 它是完整游戏角色插件，包含武器和战斗系统，穗奈不需要这些复杂度。
- 其默认角色是游戏用全身结构，不能直接套进穗奈的半身陪伴窗口。

### Godot 官方 Cutout Animation 示例

项目地址：`https://docs.godotengine.org/en/stable/tutorials/2d/cutout_animation.html`

借鉴：

- 骨骼切片适合身体、手臂和腿等刚性结构。
- 手、脚和复杂表情可以保留为 `AnimatedSprite2D` 的逐帧动画。
- 骨骼和逐帧素材可以混用，不需要强迫一个系统承担所有动作。

## 穗奈的最终落地方式

穗奈仍然运行在当前 React + Canvas 应用中，不引入 Godot 运行时。外部项目只作为美术制作和绑定参考，实际接入由以下三层完成：

1. Pixelorama 制作 256×320 原生 PNG 图层，逻辑网格为 128×160。
2. `manifest.json` 保存图层、锚点、深度和动作帧信息。
3. TypeScript Canvas 负责按锚点装配、播放状态和业务映射；手部、眼睛、嘴形和道具允许使用手绘关键帧覆盖。

模板目录：`web/public/brand/pixel-rig-v05/`。

当前已有：

- `manifest.json`：画布、色板、图层、锚点和动作契约。
- `layers/`：10 个透明图层模板。
- `anchors-guide.png`：用于 Pixelorama 对齐的锚点参考图。
- `README.md`：分层制作顺序和检查要求。

## 验收顺序

- 先验收 `model-sheet/frame-00` 的画风、脸部、下巴、肩颈和轮廓。
- 再验收 idle 的 4 帧，确认胸口、发梢和眼睑的变化不破坏脸部。
- 再验收 listen 的 4 帧，确认手腕、袖口、手指和脸侧位置有清楚的关系。
- 最后才接入 think、encourage 和业务状态映射。

`pixel-v04` 仅保留作审美对照；不再把它作为正式动作素材继续扩展。
