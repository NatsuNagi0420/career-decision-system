# 穗奈像素角色 v0.5：画风与动作绑定规范

更新：2026-10-18。

当前 v0.4 的平面像素化素材只保留为视觉参考。它可以帮助比较色彩、脸部识别度和整体比例，但不作为动作素材继续扩展，因为一张合成图无法稳定拆出头发、肩颈、手臂和道具的前后关系。

## 先确定的画风

穗奈的目标不是把立绘缩小，也不是做马赛克滤镜，而是做一套可以长期陪伴用户的二次元像素角色：脸部要有眼神，轮廓要有像素簇，动作要有停顿和重心，界面缩小后仍然能读出她在“听、想、解释还是鼓励”。

第一版模型稿遵循这些硬约束：

- 逻辑画布使用 128×160，显示时按 2 倍放大；给头发、肩颈和双手留足动作空间。
- 头部高度控制在 62 像素以内，脸部安全区至少 44×40；不能让头部挤满画布。
- 使用 24–32 色共享色板；皮肤、头发、眼睛、眼镜、开衫、白衣和麦穗分别成组。
- 禁止渐变、半透明抗锯齿和随机抖色；轮廓用深棕、蓝灰等有色轮廓，避免整圈纯黑。
- 轮廓由连续但有节奏的像素簇组成，脸、下巴、眼镜、发梢和肩峰要人工清理孤立像素与 banding。
- 服装纹理只保留能帮助识别身体朝向的几条线，不能让肩膀变成细碎噪声。

## 绑定方式

这里的“绑定”采用 2D 切片角色的思路：代码维护状态、动作、播放和暂停，素材提供按锚点对齐的身体部件和关键姿势。它不把整张图片当作一个贴图，也不依赖 Live2D 式的连续变形。

图层从后往前固定为：

1. `hair-back`：后发和发梢，跟随头部但允许有少量延迟帧。
2. `body`：躯干、开衫和白衣，负责稳定肩线。
3. `neck-face`：脖子、脸、耳朵和下巴，作为表情主体。
4. `hair-front`：刘海、脸侧发束和麦穗发夹。
5. `glasses`：圆框眼镜，单独一层，保证视线和镜框不会被头发吞掉。
6. `arm-left`、`arm-right`：上臂和前臂，使用离散关键姿势，不在运行时任意旋转像素块。
7. `prop`：手账、笔、资料卡或文件夹。
8. `hands`：手掌和少量指尖，按照动作重新画关键帧。
9. `effects`：眨眼高光、呼吸辅助像素和状态提示。

核心锚点固定为：头心、下巴、颈根、左右肩、左右肘、左右腕、左右手和道具中心。动作先移动这些锚点，再画连接它们的袖子和手部；不能先画一整张手臂，再为了配合动作强行拉伸。

运行时只允许使用整数像素和有限的离散姿势。上臂、前臂和道具可以在草稿阶段做最近邻变换检查位置，但交付帧必须手工修正关节、袖口、手腕和轮廓。

## 首批动作

只做四种动作，且每种先做 4 帧：

| 动作 | 关系 | 关键手部目标 | 道具 |
| --- | --- | --- | --- |
| 待机 | 她在等你开口 | 双手靠近身体中线 | 手账 |
| 倾听 | 她把注意力交给你 | 一只手到脸侧，另一只手放低 | 无 |
| 思考 | 她在整理信息 | 一只手持笔靠近纸面 | 笔记 |
| 鼓励 | 她邀请你继续行动 | 一只手向前递出 | 资料卡 |

4 帧的分工固定为：进入、保持、次级运动、回收。待机只改变胸口、发梢和眼睑；倾听增加小幅点头；思考让笔尖和视线形成关系；鼓励让手掌先到位，再让头发和衣袖收尾。

## 接下来在 Pixelorama 中的制作顺序

1. 先画 `idle/frame-00` 模型稿，只处理轮廓、脸部、肩颈和服装大色块。
2. 复制模型稿建立 `listen/frame-00`，先只移动手腕和前臂，再补袖口与手指。
3. 回到四个动作的第 0 帧，确认头、颈、肩、手和道具的锚点都能对齐。
4. 再补每个动作的第 1–3 帧，使用洋葱皮检查次级运动；不通过整张图上下移动解决动画。
5. 在 1×、2×和真实桌面小窗三个尺寸验收后，再把 v0.5 接入运行时。

当前最重要的美术产物不是更多动作，而是一张比例稳定、可拆层、可复用的中性模型稿。模型稿没有通过之前，继续批量生成状态图只会扩大返工范围。
