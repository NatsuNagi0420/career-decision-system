# 穗奈用户画像页原型素材包

本素材包包含一张完整用户画像页原型图、19 枚独立透明底 PNG 图标、可编辑的 HTML/CSS/SVG 源文件，以及本说明。

## 原型图

`原型图/穗奈_用户画像页_完整原型.png` 为高分辨率静态页面视觉稿，画布外围透明，页面内容采用与穗奈现有组件一致的深靛蓝、薰衣草紫、薄荷绿和奶油白像素 UI 风格。页面依次展示：

1. 画像概览：昵称、阶段、主要目标、画像状态、最近更新时间。
2. 基本背景：专业、学历、在读状态、工作年限、当前身份。
3. 目标与方向：想解决的问题、方向、目标岗位/行业、求职计划。
4. 真实经历：负责内容、技术、产出结果及来源。
5. 技能与实践证据：阶段、使用场景、关联经历、示例原文和来源。
6. 偏好与现实限制：城市、工作方式、行业、薪资、工时边界、避开项、每周投入时间。
7. 待继续了解：信息缺口与穗奈后续追问的问题。

确认状态以颜色和文字共同表达：薄荷绿「已确认事实」、紫色「暂时判断」、桃色「待确认」。各区域尽量标出对话/文件等来源和更新时间；缺少依据的内容明确标成待确认。

## 透明图标

`透明图标/` 下有 19 枚独立 RGBA PNG：穗奈芽苗、已确认事实、暂时判断、待确认、基本背景、目标方向、项目经历、React 实践、接口开发、容器部署、来源文件、对话来源、更新时间、地点、偏好限制、待追问、行业方向、修正记录、继续箭头。

## 源文件与示例说明

`用户画像页原型源文件.html` 含可编辑的 HTML/CSS/SVG 版式与图标符号。本原型为静态视觉稿，不包含真实交互。

昵称、项目经历、原文引述、来源及日期等均是为了展示信息结构而写的**示例数据**，不代表用户真实情况。实际使用时应替换成用户明确提供、可核实的内容；没有证据就保持待确认，不应推断成事实。页面不包含岗位列表、完整学习路线、简历编辑器、联系方式、匹配百分比或性格测试结果。
