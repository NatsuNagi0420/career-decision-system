# 职业规划 Agent 像素风图标

12 枚独立 RGBA PNG，均为透明底，按同一套浅紫、薄荷绿、奶油白、蜜桃色和深蓝像素描边设计。建议 UI 尺寸 24–32 px；如需保持像素边缘，可设置 `image-rendering: pixelated`。

| 文件 | 建议用途 |
|---|---|
| `01_new_chat.png` | 新建对话 |
| `02_chat_history.png` | 对话历史 |
| `03_upload_resume.png` | 上传简历/附件 |
| `04_send_message.png` | 发送消息 |
| `05_project_folder.png` | 项目资料 |
| `06_goal_target.png` | 职业目标 |
| `07_strengths_star.png` | 优势与成就 |
| `08_career_compass.png` | 职业方向探索 |
| `09_action_plan.png` | 行动计划 |
| `10_source_search.png` | 资料/来源检索 |
| `11_settings.png` | 设置 |
| `12_complete.png` | 完成状态 |


这些是静态 PNG 图标素材；可以按产品最终视觉继续做像素网格统一和尺寸导出。
