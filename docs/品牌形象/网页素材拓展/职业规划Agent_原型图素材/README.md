# 职业规划 Agent 原型图素材包

本包从两张像素风 UI 原型中整理出可单独复用的 PNG 素材。角色和猫咪已抠为透明底；图标保留必要的徽章/色块并移除了外部界面底色。

## 内容

- `角色/`：两版 Live2D 立绘 PNG（静态抠图，不包含 Live2D 骨骼、动作或工程文件）。
- `猫咪/`：趴卧猫咪贴图与猫咪头像图标。
- `房间背景/`：两版独立像素场景背景。背景图自身为完整不透明的场景画面；四周添加了透明边距，便于叠放和定位。
- `图标/`：品牌芽苗、星星、爱心、芽苗、笔记本、指南针与对话助手头像等 UI 图标。

## 文件格式

所有文件均为 PNG/RGBA，带 alpha 通道。角色、猫咪和图标的画布背景透明；房间背景作为完整场景图块，图块外沿透明（场景内部保持不透明是背景图的正常属性）。这些素材适合继续放入 UI/游戏项目中排版；原型截图未打包。
