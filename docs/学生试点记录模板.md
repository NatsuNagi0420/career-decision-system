# 第一版学生试点记录模板

本模板只记录匿名参与者编号和产品观察，不记录姓名、手机号、邮箱、学校全称或完整聊天内容。真实记录保存在 Git 已忽略的 `pilot-results/` 或独立的受控研究目录，不提交到公开仓库。

## 数据库指标

所有试点账号使用同一个、不会与 `smoke`、`test` 或 `demo` 混淆的前缀。运行：

```powershell
.\scripts\report-pilot-metrics.ps1 `
  -CohortPrefix "pilot26" `
  -RegisteredFrom "2026-08-01" `
  -RegisteredBefore "2026-09-01" `
  -RequireAcceptance
```

脚本只输出匿名编号、时间和布尔指标，不输出用户名、联系方式、项目文本、成果正文或聊天内容。`-RequireAcceptance` 只有在批次包含 10 至 15 人，且至少一人完成“确认目标、完成任务、记录成果、提交复盘、复盘后继续行动”时才通过。

## 验收结论

- [ ] 真实参与者共 10 至 15 人。
- [ ] 至少一人完成完整决策和首个任务成果。
- [ ] 至少一人于下一周提交复盘并继续执行或调整任务。
- [ ] Android 真机与 Web 读取到相同任务结果。
- [ ] 真实模型输出和规则降级均有实际记录。
- [ ] 未把 smoke、自动化或开发者自测账号计入试点数据。
