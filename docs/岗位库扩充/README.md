# 岗位库扩充交接

交接日期：2026-10-24。

## 如何使用

1. 将《给采集AI的完整提示词.md》代码块内全文复制给能联网、能导出文件的 AI，不需要上传项目源码或账号。
2. 采集范围暂按计算机相关在校生/应届生、五个方向、100–150 条设计。这是首批建议范围和目标，不是产品已确定只服务这些人，也不是统计代表性保证。
3. 将其返回的 ZIP 或数据文件放进 `待导入/`，再由当前项目检查和导入。

## 附件

- `给采集AI的完整提示词.md`：可独立使用的一整段任务提示。
- `jobs.template.csv`：只有表头，无虚构示例；CSV 的 locations、evidence 两列存 JSON 字符串。
- `job-collection.schema.json`：单条 JSONL 记录的交换格式。它不是当前 Agent 的历史快照结构。
- `已核查来源线索_20261024.csv`：6 个来源入口及本次可访问程度；不是 6 条已验收岗位。
- `待导入/`：放置外部 AI 返回的文件，不自动执行或自动入库。

## 数据进入系统的顺序

公开来源材料 → 格式/日期/逐字引文/去重校验 → 隔离异常 → 保留来源的入库批次 → 穗奈检索和解释 → 用户确认后保留到个人工作台。

先形成结构化事实底库和可追溯原文。若后续确有检索需要，再加语义索引；不要同时维护相互矛盾的“数据库版”和“知识库版”事实。专业知识、学习路线与模型建议不是雇主 JD，不混写进岗位原文。
