第一章 绪论
1.1 项目背景与意义
随着高校毕业生人数逐年增加，大学生就业压力不断增大。据统计，2025年全国高校毕业生人数达到1174万人，创历史新高。然而，传统职业规划服务存在以下问题，信息不对称，个性化不足，技术落后。
智能职业规划平台应运而生，通过AI技术赋能，为大学生提供精准、个性化的职业发展指导，有效缓解大学生就业焦虑，提升职业规划的科学性和实用性，具有重要的现实意义和应用价值。
1.2 项目定位
以AI技术为核心，提供全流程、个性化的职业规划解决方案，涵盖信息收集、能力测评、岗位匹配、路径规划等全环节，打破传统职业规划的局限。在校生及应届毕业生，覆盖不同专业、不同年级，聚焦有职业规划需求、面临就业选择的青年群体。技术领先，深度集成AI大模型；用户体验优秀，响应式设计适配多终端；数据驱动，基于用户数据实现精准匹配和个性化推荐。

第三章  核心功能模块设计与实现
3.1 用户认证模块
构建完整的用户注册登录系统，保障用户数据安全和系统访问安全，实现用户身份的有效验证和权限控制。JWT Token认证，采用无状态认证机制，生成安全的Token用于用户身份验证，避免会话存储带来的性能压力。会话管理，实现Token自动续期，支持用户安全退出，确保会话的安全性和便捷性。权限控制，实现接口级别的权限验证，不同角色用户访问不同接口，保障系统数据的安全性。
3.2 信息录入模块
提供多种方式收集用户个人信息，为后续的能力测评和职业规划提供数据支撑，降低用户信息录入的难度，提高录入效率。快速录入，提供基础信息快速填写表单，涵盖姓名、专业、年级、联系方式等核心信息，快速完成信息采集。综合录入，提供详细个人信息收集表单，涵盖教育经历、实习经历、技能证书、兴趣爱好等信息，全面了解用户情况。简历解析，支持PDF、Word格式简历的智能解析，自动提取简历中的核心信息，填充到系统表单中，减少用户手动录入工作量。
3.3 MBTI测评模块
构建专业的MBTI心理测评系统，通过科学的题目测评，识别用户的人格类型，为职业匹配提供心理层面的支撑。
93道专业题目，覆盖E/I（外向/内向）、S/N（感觉/直觉）、T/F（思考/情感）、J/P（判断/感知）4个维度，全面评估用户人格类型。用户完成每道题目后，系统动态计算各维度得分，实时更新测评进度和初步结果。测评完成后，生成个性化的人格分析报告，解读人格特点、适合的职业方向、职业发展建议等内容。
3.4 深度问卷模块
设计专业的职业倾向与能力评估问卷，多维度了解用户的职业兴趣、能力特长、价值观等，为能力画像生成和岗位推荐提供数据支撑。
30题专业问卷，涵盖职业兴趣、能力自评、价值观倾向、职业期望等多个维度，全面评估用户的职业适配性。通过AI算法对用户的问卷答案进行智能分析，识别用户的职业倾向和能力优势。结合问卷结果，生成个性化的能力雷达图，直观展示用户的各项能力分布情况。
3.5 能力画像模块
基于用户的信息录入、MBTI测评、深度问卷结果，通过AI算法生成个性化的能力分析，帮助用户清晰认识自身优势与不足。
通过ECharts生成能力雷达图，可视化展示用户的沟通能力、学习能力、执行能力等各项能力的分布情况。技能标签，智能识别用户的核心技能，生成个性化的技能标签，如“数据分析能力”“沟通协调能力”等。结合用户的能力短板和职业倾向，提供针对性的能力提升建议，帮助用户明确努力方向。
3.6 岗位推荐模块
基于用户的能力画像、职业倾向等数据，通过AI算法实现岗位与用户的精准匹配，为用户推荐合适的职业岗位。
从技能、兴趣、价值观、人格类型等多个维度进行匹配，确保推荐岗位的适配性。根据匹配度高低对岗位进行排序，优先推荐匹配度高的岗位，方便用户快速筛选。展示岗位的详细信息，包括岗位职责、任职要求、薪资范围、行业前景等，帮助用户全面了解岗位。
3.7 路径规划模块
基于用户选择的目标岗位，通过AI算法生成个性化的职业发展路径，可视化展示职业发展的各个阶段，帮助用户明确发展目标。
结合目标岗位的任职要求和用户的当前能力，生成个性化的职业发展路径，明确各阶段的发展目标。通过ECharts生成力导向图，交互式展示职业发展的各个阶段、关键节点和提升方向。将职业发展路径分解为短期、中期、长期三个阶段，明确每个阶段的具体目标和实施步骤。
3.8 报告归档模块
对用户的职业发展报告进行统一管理，支持报告的生成、下载、存档和查看，方便用户跟踪自身职业发展历程。
将用户的能力画像、岗位推荐、路径规划等内容整合为专业格式的PDF报告，支持在线查看和下载。对用户生成的多版本报告进行存档，用户可随时查看历史报告，对比自身职业发展变化。记录用户的职业规划进度，跟踪用户各阶段目标的完成情况，提醒用户及时调整发展计划。
3.9 AI助手模块
集成AI助手，为用户提供全程智能辅助，解答用户在职业规划过程中遇到的问题，引导用户完成各项操作。24小时在线咨询，支持自然语言对话，解答用户关于职业规划、岗位选择、能力提升等方面的问题。为用户提供步骤化的操作指导，引导用户完成信息录入、测评、岗位选择等各项操作，提升用户使用体验。结合用户的具体情况，提供个性化的职业发展建议，帮助用户优化职业规划方案。
第四章 业务流程设计
4.1 五步闭环流程
业务流程采用可视化方式展示，清晰呈现各环节的衔接关系，具体流程如下：
graph TD    A[信息录入] --> B[能力画像生成]    B --> C[岗位探索选择]    C --> D[路径规划]    D --> E[报告生成归档]    E --> A        F[AI助手全程辅助] --> A    F --> B    F --> C    F --> D    F --> E
4.2 详细流程说明
用户完成系统注册/登录，进入信息录入页面；选择快速录入或综合录入方式，手动填写基础信息或详细信息。可上传PDF/Word格式简历，系统通过智能解析自动提取信息，填充到表单中。系统对录入的信息进行验证，确保信息的完整性和准确性，验证通过后保存至数据库。
用户进入MBTI测评页面，完成93道专业题目测评（约15分钟）。测评完成后，进入深度问卷页面，填写30道专业问卷（约10分钟）。系统结合用户的信息录入、MBTI测评、深度问卷结果，通过AI算法生成能力分析报告。用户查看能力画像，包括能力雷达图、技能标签和发展建议，确认自身能力情况。
系统基于用户的能力画像、职业倾向等数据，通过AI算法推荐匹配度高的岗位。用户浏览岗位列表，查看岗位详情，了解岗位职责、任职要求等信息。用户根据自身兴趣和职业期望，选择1-3个目标岗位作为职业发展方向。系统记录用户选择的目标岗位，为后续路径规划提供依据。
系统结合目标岗位的任职要求和用户的当前能力，通过AI算法生成个性化的职业发展路径。以力导向图的形式可视化展示职业发展的短期、中期、长期目标，以及各阶段的提升方向。用户查看路径规划结果，可根据自身情况调整各阶段目标和实施步骤。系统保存用户确认后的路径规划方案，方便用户后续跟踪执行。
系统将用户的能力画像、岗位推荐、路径规划等内容整合，生成完整的职业发展报告。用户可在线查看报告，也可下载PDF格式报告，用于后续参考和使用。系统对用户生成的报告进行存档，用户可随时查看历史报告，对比自身职业发展变化。用户可根据自身发展情况，重新进行信息录入、测评等操作，生成新的职业发展报告，形成闭环。

5.2.2 离线支持

第六章 技术亮点详解
6.1 大模型集成技术
系统封装了AiUtils工具类，支持多种AI服务协议，实现了AI服务的统一调用和管理，同时设计了智能兜底机制，确保AI服务的稳定性，核心代码如下：
javapublic class AiUtils {    // OpenAI兼容接口，调用OpenAI大模型获取响应    public static String callOpenAI(String prompt) {        // 实现逻辑：构建请求参数，调用OpenAI API，获取响应结果        String apiKey = "your-openai-api-key";        String url = "https://api.openai.com/v1/chat/completions";        // 构建请求体，发送POST请求，解析响应结果        return response;    }        // Anthropic协议支持，调用Anthropic大模型获取响应    public static String callAnthropic(String prompt) {        // 实现逻辑：构建请求参数，调用Anthropic API，获取响应结果        String apiKey = "your-anthropic-api-key";        String url = "https://api.anthropic.com/v1/messages";        // 构建请求体，发送POST请求，解析响应结果        return response;    }        // 智能兜底机制，当AI服务失败时使用本地数据返回    public static String smartFallback(String prompt) {        try {            // 先尝试调用OpenAI接口            return callOpenAI(prompt);        } catch (Exception e1) {            try {                // OpenAI失败，尝试调用Anthropic接口                return callAnthropic(prompt);            } catch (Exception e2) {                // 所有AI服务失败，返回本地预设的兜底响应                return getLocalFallbackResponse(prompt);            }        }    }        // 本地兜底响应，根据prompt类型返回预设内容    private static String getLocalFallbackResponse(String prompt) {        // 预设不同类型prompt的兜底响应，确保服务不中断        if (prompt.contains("职业推荐")) {            return "根据你的能力画像，推荐你关注互联网、教育等行业的相关岗位，具体可查看系统岗位推荐列表。";        } else {            return "当前AI服务暂时不可用，请稍后再试，或查看系统提供的基础职业规划建议。";        }    }}
6.2智能简历解析
通过Apache Tika的PDFParser解析PDF格式简历，提取文本内容，处理PDF中的图片、表格等元素，确保文本提取的完整性。支持.doc、.docx等Word格式简历解析，保持文档原有的格式结构，准确提取姓名、联系方式、教育经历等核心信息。结合正则表达式和关键词匹配，自动识别简历中的姓名、性别、联系方式、教育经历、实习经历、技能证书等核心字段，将提取的信息自动填充到系统表单中，减少用户手动录入工作量。
6.3 安全认证机制
系统采用JWT + 拦截器的双重安全保障机制，实现用户身份的有效验证和接口权限控制，确保系统数据的安全性，核心实现如下：
java@Componentpublic class AuthInterceptor implements HandlerInterceptor {    @Override    public boolean preHandle(HttpServletRequest request,                            HttpServletResponse response,                            Object handler) throws Exception {        // 1. 获取请求头中的Token        String token = request.getHeader("Authorization");        if (token == null || token.isEmpty()) {            // 无Token，返回401未授权            response.setStatus(HttpServletResponse.SC_UNAUTHORIZED);            response.getWriter().write("请先登录");            return false;        }                // 2. 验证Token的有效性        boolean isValid = AuthContext.verifyToken(token);        if (!isValid) {            // Token无效或过期，返回401未授权            response.setStatus(HttpServletResponse.SC_UNAUTHORIZED);            response.getWriter().write("Token无效或已过期，请重新登录");            return false;        }                // 3. Token有效，放行请求        return true;    }}
通过拦截器拦截所有需要权限验证的接口，对Token进行验证，确保只有合法用户才能访问系统接口，同时实现Token自动续期机制，提升用户使用体验。
