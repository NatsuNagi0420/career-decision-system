## 1. 文档目的

本文档用于统一青穗集品牌与穗奈 IP 形象的创作方向，并作为图像模型生成、人工精修、矢量化和跨端品牌资产导出的共同依据。

本文档只约束品牌相关内容，不调整产品已经确定的默认配色、Material Design 3 主题系统或莫奈动态取色逻辑。品牌资产必须能够在现有浅色、深色和动态配色页面中稳定使用。

## 2. 品牌基础

### 2.1 品牌名

**青穗集**

- **青**：对应青葱校园、青年学生和仍在生长的人生阶段。
- **穗**：对应从青苗到抽穗的阶段性成长，以及经过积累后获得的成果。
- **集**：对应手账、记录与合集，也承载方向、证据、计划、行动和复盘等成长内容。

### 2.2 品牌意境

青穗集是一册持续生长的数字手账。用户不是一次完成测评后获得固定结论，而是在探索、比较、行动和复盘中逐步积累证据，让方向由模糊变得清晰。

品牌应呈现自然、清新、温和和有秩序的感受，同时保持职业决策产品所需的可信度与行动感。品牌表达不能退化为纯文学刊物、农产品品牌或只有装饰作用的治愈系手账。

### 2.3 对外信息结构

正式场景建议同时使用品牌名和功能描述：

```text
青穗集
大学生职业决策与行动助手
```

品牌主张：

```text
把选择理清，把成长走实
```

### 2.4 品牌关键词

- 成长
- 梳理
- 记录
- 选择
- 行动
- 收获
- 校园
- 陪伴
- 清晰
- 可信

### 2.5 品牌表达禁区

- 不使用“包就业”“精准预测”“替你决定”等承诺性表达。
- 不把成长描述成单一、笔直或人人相同的路线。
- 不把品牌包装成考试培训、招聘中介或单次职业测评工具。
- 不使用农田、丰收庆典、乡村民宿等容易造成行业误解的主视觉。
- 不依赖“职、考、码、学”等功能词构成品牌识别。

## 3. IP 角色定位

### 3.1 角色名称

**穗奈**，读音为 `suì nài`。

“穗”与青穗集形成弱命名联动，“奈”用于建立柔和、独立的动漫角色感。穗奈可以在头像、表情包和插画中独立出现，但必须通过固定视觉锚点保持与青穗集的品牌关系。

### 3.2 一句话设定

穗奈是一名喜欢用手账整理生活的普通大学生。她不替别人决定未来，而是陪伴用户发现线索、整理选择、记录行动，并在迷茫时一起找出下一步。

### 3.3 角色职责

- 引导用户把模糊问题拆成可以思考和行动的内容。
- 帮助用户整理个人经历、岗位信息和行动证据。
- 在关键节点提醒用户确认，而不是代替用户做决定。
- 用简洁、温和的方式反馈进度和风险。
- 通过手账、便签和阶段记录强化长期陪伴感。

### 3.4 角色边界

- 穗奈不是全知导师、招聘官、心理咨询师或成功学偶像。
- 穗奈不保证职业结果，不给出唯一正确答案。
- 穗奈可以表达关心、疑问和鼓励，但不能用卖萌弱化风险提示。
- AI 生成的建议仍需遵循产品中的授权、可解释和用户确认规则。

### 3.5 基础档案

| 项目 | 设定 |
| --- | --- |
| 身份 | 在校大学生、手账记录爱好者 |
| 年龄感 | 成年大学生，不幼态化 |
| 核心性格 | 温和、细致、清醒、有耐心 |
| 次要性格 | 偶尔犹豫，但擅长把混乱重新整理清楚 |
| 兴趣 | 写手账、整理便签、观察校园植物、记录阶段成果 |
| 擅长 | 提问、归纳、拆分下一步、持续记录 |
| 不擅长 | 替别人拍板、夸张表达、空泛说教 |
| 口吻 | 平等、简洁、具体，像一起整理思路的同伴 |
| 标志物 | 麦穗路径发夹、随身手账、索引便签 |

### 3.6 语言风格示例

推荐：

- “先不用急着选，我们把你已经知道的线索放在一起。”
- “这个方向还缺一条真实岗位证据，要不要把它加入下一步？”
- “你已经完成了第一轮比较，现在可以确认最想验证的一个问题。”
- “这周留下的成果，会成为下一次选择时更可靠的依据。”

避免：

- “听我的，这个职业最适合你。”
- “只要坚持就一定能成功。”
- “根据 AI 精准计算，你应该选择这个方向。”
- 过量使用语气词、颜文字、网络热梗或幼态称呼。

## 4. 角色视觉设定

### 4.1 总体方向

穗奈应是具有原创辨识度、偏日漫表现方式的现代校园动漫角色。整体气质自然、清爽、亲和，具备日常陪伴感，不采用偶像歌姬、魔法少女、教师或企业顾问造型。

角色设计可以带有自然治愈气息，但服装、道具和姿态必须让她属于当代大学校园，而不是田园幻想世界。

### 4.2 外形基线

以下内容作为首轮概念生成基线，定稿后必须固化为角色设定表：

- 成年大学生比例，身形自然，不使用儿童化头身比作为标准立绘。
- 中长发，发尾在肩部以下、胸部以上，整体轮廓柔和，发尾带轻微外翘或自然弧度。
- 使用轻薄、有空气感的偏分刘海，额头保留适量留白，双眼与双侧眉毛完整可见；发丝不能遮挡眼睛。
- 标准发色为明亮栗棕色，在光照下带少量蜂蜜金色层次，不使用黑灰、青黑或墨绿色头发。
- 标准瞳色为清透琥珀金，采用图形化色块，不使用写实玻璃质感和强发光效果。
- 表情亲和、温柔，默认状态带自然的轻微笑意；眼神应让人愿意接近和交流，不表现得冷淡或高高在上。
- 五官应保留成熟大学生感，避免幼童脸、过度腮红和玩偶化比例。
- 脸部采用明确的二维漫画绘制逻辑：粗细有变化的深色线稿、图形化眼睛、简化鼻形和可读的嘴形。
- 虹膜只使用少量清晰色块和一至两个高光，不使用玻璃球质感、多层放射纹或写实湿润反光。
- 肤色以平涂为主，只在刘海下、下颌和颈部保留一级硬边赛璐璐阴影，不使用空气刷渐变和瓷器般磨皮。
- 眉眼与嘴角保留轻微自然不对称，腮红使用少量短排线或色块，不使用大面积柔焦红晕。

### 4.3 服装基线

- 现代校园休闲装与轻学院风结合，偏日漫角色设计，但不使用校服。
- 标准造型建议使用明亮天蓝色针织开衫、象牙白内搭、海军蓝膝上百褶短裙、白色短袜和焦糖色低帮日常鞋。
- 服装结构简洁，全身轮廓应具有明确识别度，并能自然派生为半身像、头像和小尺寸形象。
- 可使用少量植物或手账索引元素，不将麦穗铺满服装。
- 不使用传统日式水手服、偶像舞台服、职业套装、白大褂、长裙或奇幻裙装。
- 不通过暴露服装、夸张身体比例或暧昧姿态吸引注意。

### 4.4 固定视觉锚点

以下锚点用于保证穗奈与青穗集的长期品牌联系：

1. **麦穗路径发夹**：由简化麦穗、路径分岔和节点共同构成，是最重要的识别物。
2. **随身手账**：封面使用青穗集核心标记，侧边带有少量分类索引。
3. **成长便签**：用于插画叙事和交互反馈，可表现待验证问题、行动记录和阶段成果。
4. **节点线条**：角色周围可有限使用轻量路径或节点图形，但不能形成大面积科技 HUD。

发夹必须能够独立简化为品牌标记。手账可以随场景变化，但封面标记的位置和基本比例应保持一致。

### 4.5 建议表情组

首批至少制作以下 8 种表情：

1. 默认微笑
2. 专注倾听
3. 思考
4. 发现线索
5. 温和提醒
6. 为难或不确定
7. 完成后的安心
8. 轻度鼓励

表情差异主要通过眉眼、嘴型和轻微头部姿态表达，避免依赖夸张符号和大幅肢体变形。

### 4.6 建议动作组

- 双手拿着打开的手账。
- 单手翻页，另一只手指向已整理的便签。
- 坐在校园公共空间中记录。
- 面向用户展示一个待确认的选项。
- 把完成的便签放入“成果”页。
- 在分岔路径前停下思考，而不是直接指向唯一方向。

## 5. 品牌标记与角色版 Logo

### 5.1 品牌标记概念

核心标记应将以下三个语义压缩成一个简洁图形：

- 麦穗：阶段成长与收获。
- 路径：选择、验证和行动。
- 节点：经历、岗位信息和成果证据。

推荐结构为“一条茎秆形成路径，少量麦粒形成证据节点，顶部由分岔重新收拢”。标记不能直接绘制完整麦田、麦捆、书本或传统农业徽章。

### 5.2 Logo 层级

| 层级 | 构成 | 主要用途 |
| --- | --- | --- |
| 核心标记 | 麦穗路径几何符号 | favicon、通知图标、小尺寸状态 |
| 标准字标 | 核心标记 + “青穗集” | 顶部导航、文档、展板 |
| 信息组合 | 标准字标 + 功能描述 | 登录页、启动页、正式介绍 |
| 角色组合 | 穗奈全身形象 + 标准字标 | 品牌展示、宣传物料、欢迎场景 |
| IP 独立形象 | 穗奈头像、立绘或表情 | AI 助手、引导、反馈和内容运营 |

### 5.3 使用原则

- 完整人物不能作为唯一 Logo 源文件。
- 穗奈的标准品牌形象以完整全身立绘为主，必须完整呈现头顶至鞋底，不得用半身像代替角色主设定。
- favicon 和通知图标只使用核心标记，不使用人物五官或文字。
- App 图标可使用经过专门简化的穗奈头像，但必须保留麦穗路径发夹。
- 角色组合 Logo 优先使用全身形象，只用于有足够空间的场景，不能强行压缩到小尺寸；半身像与头像仅作为紧凑场景的派生版本。
- 生成模型不得直接生成最终中文字标，正式字标必须人工排版和校正。
- 品牌资产必须同时提供全彩、深色底、浅色底和单色版本。
- 单色版本用于兼容莫奈动态主题，不反向修改页面主题色。

## 6. 生成式图像制作流程

### 6.1 制作顺序

1. 生成穗奈的多个全身外形方向，不加入品牌文字，并完整呈现头顶至鞋底。
2. 评审并锁定发型、脸型、瞳色、服装、发夹和手账。
3. 生成标准全身立绘与全身三视图，再从定稿全身形象派生半身像、头像和表情组。
4. 单独生成核心标记概念，不让模型处理中文字形。
5. 人工重绘核心标记并制作 SVG 母版。
6. 使用定稿角色和 SVG 标记制作角色版组合 Logo。
7. 导出跨端资源并执行小尺寸、深浅底和动态主题验收。

## 7. 角色一致性要求

### 7.1 必须锁定的特征

首轮定稿后，以下内容必须记录为可重复使用的角色基准：

- 正面、侧面和背面发型轮廓。
- 发色、瞳色和肤色色值或参考样本。
- 麦穗路径发夹的准确结构、位置和朝向。
- 标准服装的领口、袖口、外套长度和主要配件。
- 手账尺寸、封面标记和索引便签数量范围。
- 成年角色的头身比例、脸型与身高感。
- 默认表情与眉眼特征。

### 7.2 生成约束

- 后续图片必须以定稿角色设定图作为视觉参考，不能只依赖文字提示词重新抽取角色。
- 同一组资产应固定生成模型、主要参数、参考图和提示词版本。
- 每次生成后检查发夹、手账标记、发型分区、瞳色和服装结构。
- 不因节日或主题活动随意改变角色的核心识别物。
- 新服装可以变化，但发夹与至少一个品牌锚点必须保留。

## 9. 验收标准

### 9.1 品牌识别

- 不阅读文字时，核心标记仍能表达“成长中的路径”，且不被首先识别为农产品品牌。
- 穗奈单独出现时可以通过发夹和手账识别其与青穗集的关系。
- 角色具有明确原创特征，与常见虚拟歌姬、校园手游角色和通用 AI 助手存在明显差异。

### 9.2 小尺寸与跨主题

- 核心标记在 16、24、32、40 和 48 像素下轮廓清晰。
- 穗奈头像在 48 像素下仍能识别发型和发夹，不要求保留细小服装纹理。
- 全彩、浅底、深底和单色版本均通过可读性检查。
- 品牌资产在现有默认主题和莫奈动态主题中可用，不要求主题为品牌资产改变颜色规则。

### 9.3 角色质量

- 标准立绘表现为成年大学生，不幼态化或性化。
- 服装、道具和校园语境可信，不采用舞台、奇幻或职业导师制服。
- 表情可以覆盖引导、思考、提醒、完成和不确定等产品状态。
- 同批资产中的脸型、发型、发夹、瞳色和手账结构保持一致。

### 9.4 权利与来源

- 不使用官方动漫、游戏、虚拟歌手、画师作品或其显著特征作为参考成品。
- 保留生成工具、模型版本、提示词、参考图、生成日期和人工修改记录。
- 正式发布前完成品牌名商标、应用商店重名和角色视觉相似性检查。
- 确认所用生成服务和后续字体、素材具有对应商业使用权限。
