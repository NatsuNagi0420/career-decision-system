# 项目部署文档

## 1. 迁移到新电脑时需要打包的目录与文件

### 1.1 必须打包（运行必需）

按当前项目结构，建议至少打包以下内容：

- `backend/ba/src/`（后端源码）
- `backend/ba/sql/career_db.sql`（数据库初始化脚本）
- `backend/ba/pom.xml`（后端依赖定义）
- `backend/ba/mvnw`
- `backend/ba/mvnw.cmd`
- `backend/ba/.mvn/wrapper/`（Maven Wrapper 配置）
- `frontend/fr/src/`（前端源码）
- `frontend/fr/public/`（前端静态资源）
- `frontend/fr/package.json`
- `frontend/fr/package-lock.json`
- `frontend/fr/vite.config.ts`
- `frontend/fr/index.html`
- `frontend/fr/.env`（环境变量，迁移后按新机器 IP/域名调整）
- `server/images/`（后端静态图片资源目录）
- `server/videos/`（后端静态视频资源目录）

### 1.2 建议一起打包（便于协作与维护）

- `docs/`（项目文档）
- `backend/ba/HELP.md`
- `frontend/fr/README.md`
- `frontend/fr/tsconfig*.json`
- `frontend/fr/eslint.config.ts`
- `frontend/fr/env.d.ts`

### 1.3 不需要打包（可在新环境重新生成）

- `frontend/fr/node_modules/`
- `frontend/fr/dist/`
- `frontend/fr/dist-ssr/`
- `backend/ba/target/`
- `**/*.log`
- IDE 缓存目录（如 `.idea/`、`.vscode/` 中私有配置）

## 2. 新电脑部署步骤（Windows）

## 2.1 环境准备

请先安装：

- JDK 21（与 `backend/ba/pom.xml` 中 `java.version=21` 一致）
- Maven 3.9+（或直接使用项目自带 `mvnw.cmd`）
- Node.js 20.19.0+（`frontend/fr/package.json` engines 要求）
- MySQL 8.x
- Git（可选）

## 2.2 解压与目录放置

将项目解压到目标路径，例如：

- `D:\Project\服创`

保持目录结构不变（尤其是 `backend`、`frontend`、`server` 三个目录同级）。

## 2.3 初始化数据库

1. 在 MySQL 中创建数据库：`career_db`
2. 执行脚本：`backend/ba/sql/career_db.sql`

可使用命令（示例）：

```bash
mysql -uroot -p -e "CREATE DATABASE IF NOT EXISTS career_db DEFAULT CHARACTER SET utf8mb4;"
mysql -uroot -p career_db < backend/ba/sql/career_db.sql
```

## 2.4 配置后端

编辑 `backend/ba/src/main/resources/application.properties`：

- `spring.datasource.url`
- `spring.datasource.username`
- `spring.datasource.password`
- AI 相关配置（建议使用环境变量注入）：
  - `AI_API_KEY`
  - `AI_API_BASE_URL`
  - `AI_API_MODEL`

> 建议：不要把真实 API Key 明文写入仓库，优先使用系统环境变量。

## 2.5 启动后端

在 `backend/ba` 目录执行：

```bash
mvnw.cmd spring-boot:run
```

或：

```bash
mvn -DskipTests clean package
java -jar target/ba-0.0.1-SNAPSHOT.jar
```

默认端口：`8080`（见 `application.properties`）。

## 2.6 配置并启动前端

1. 编辑 `frontend/fr/.env`，设置后端地址：

```env
VITE_API_BASE_URL=http://<后端IP或域名>:8080/api
```

2. 在 `frontend/fr` 执行：

```bash
npm ci
npm run dev
```

默认前端端口：`5173`。

## 2.7 验证部署

启动后按以下链路验证：

1. 打开前端页面并登录
2. 完成信息录入 -> 能力画像 -> 岗位探索 -> 路径规划 -> 报告生成
3. 在报告页点击“保存归档”
4. 从头像进入“我的报告”，检查历史列表与详情是否可用

## 3. 常见问题排查

### 3.1 前端提示网络错误

- 检查 `frontend/fr/.env` 的 `VITE_API_BASE_URL` 是否指向可访问的后端地址。
- 检查后端 `server.port` 与防火墙是否放通。

### 3.2 登录后调用接口仍提示未登录

- 确认浏览器 Cookie 中存在 `token`。
- 确认请求头包含 `Authorization: Bearer <token>`。
- 确认后端 `WebConfig` 已拦截 `"/api/report/**"`、`"/api/path-plan/**"`、`"/api/capability/**"` 等受保护接口。

### 3.3 静态图片/视频访问异常

- 确认 `server/images/` 与 `server/videos/` 已随项目迁移。
- 确认后端静态资源映射路径与实际目录一致。

## 4. 推荐的交付打包方式

建议打两份压缩包：

1. **源码包（推荐）**：包含第 1.1 + 1.2 节内容，目标机自行安装依赖并构建。
2. **运行包（可选）**：在源码包基础上附带已构建产物（如 `frontend/fr/dist`、后端 jar），用于快速演示。

如果用于长期维护，优先交付源码包。
