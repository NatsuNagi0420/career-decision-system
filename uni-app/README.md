# 青穗集 Uni-app 小程序

穗奈的移动协作端。使用官方账号继续电脑或云端对话，查看任务、处理授权和获取成果，同时管理职业成长资料。小程序不单独实现模型推理或执行环境。

## 交互反馈（2026-11-02）

页面显示时，主要内容块轻移进入；缓存页面返回时也可重播，不重建页面、不隐藏正文、不等待计时器。首帧占位逻辑保持独立，固定底栏、底部操作区和弹层容器不参与内容位移。长任务和岗位列表作为一组播放。

按钮、卡片与来源选择器统一提供即时按压和松开回弹，按钮带局部光晕，列表箭头有轻微跟随。子按钮独立反馈，避免下载或更多操作带动父卡片。微信原生底栏记住实际离开的页签，跨缓存实例播放底块滑移及图标回弹；选中状态仍跟随实际路由，导航不等待动画完成。分段选择和弹层沿用现有滑移／进出场行为。系统要求减少动态效果时关闭相应动画。

只调整小程序前端。验证日志与本机合成数据截图见 `logs/microinteractions-20261102/`；微信端构建通过，最终原生动画手感尚未取得可复核的模拟器录像。

## 状态首页（2026-11-02）

首页采用状态概览：当前目标、真实行动完成环、今天建议推进的一步、继续对话和最近成果。没有目标时使用原穗奈素材引导探索；没有行动时不显示空进度环，不填入演示任务。画像数量按已有资料类别统计，岗位数量按已有岗位记录统计，不推断经历条数、简历数量或能力分数。

今日行动优先使用进行中项，再使用待开始项；点击后把目标、关联岗位、学习内容、交付物及进展带入同一来源的对话草稿，由用户确认发送。全部行动完成时改为回顾成果。资料来源在首页可切换，旧来源、旧账号请求不能覆盖新资料；读取失败保留已加载正文并允许重试。

原有会话列表保留在“全部对话”，搜索、来源筛选、重命名、归档、恢复和永久删除沿用原有流程。任务授权、设备与同步和文件预览／下载入口保留。首个底栏入口更名为“首页”。本轮只改小程序前端，继续使用已有接口。

验证记录和手机网页截图：`logs/home-status-20261102/`。

| 主入口 | 内容                                                       | 相关子页面                             |
| ------ | ---------------------------------------------------------- | -------------------------------------- |
| 首页   | 当前目标、行动进度、今日一步、继续对话与成果；保留全部会话管理 | 职业资料、行动详情、会话列表与文件预览 |

## 移动协作流程（2026-10-31）

首页以穗奈陪伴区和继续对话为主；待确认、电脑状态与最近文件使用紧凑入口。陪伴区可以收起并在本机记住偏好。任务页用最多三个并发检查全部可访问会话；同步中显示已检查数量，失败时保留已有结果并提示不完整。账号切换会清空该账号的缓存与待发送草稿。

对话底部“成长记录”读取当前执行来源的真实建议，云端建议通过带版本号的接口确认，过期建议回到对话重新核对。电脑建议回到相同来源的对话中核对，不写入云端资料。建议列表属于本位置；Hub 会话编号与本地职业建议编号无法直接等同，因此不声称列表中的每条建议均由当前会话生成。确认后的入口连到画像、岗位、行动与简历；本次打开过的来源会优先续用原 Hub 会话，草稿不会自动发送。

聊天附件和简历页都支持 PDF、DOCX（最多 4 MB）以及文本资料（最多 1 MB）。资料选中后先暂存，用户发送且同意模型调用后才上传。上传成功表示文件已交给 Hub，内容由执行端开始任务时解析；电脑离线时继续等待原电脑。扫描或加密 PDF 不承诺 OCR，旧 DOC 需先另存为 DOCX 或 PDF。

回归说明和截图保存在 logs/mobile-six-improvements-20261031/。浏览器视觉与接口交互使用合成数据，未消耗模型额度；文件选择的浏览器自动化受到 Chrome 扩展权限限制，使用微信选择器模拟及大小边界回归补充验证，仍需在微信开发者工具完成一次真实文件解析验收。

## 对话与成长页面改版（2026-11-01）

对话首页沿用原穗奈形象，加入可收起的陪伴区、已有会话继续入口和本地点击反馈。待确认与设备状态并排展示，最近文件折叠展示，继续使用原有预览与下载入口。首页移除了仅为欢迎提示请求账号资料的逻辑。

成长页将现有职业资料组织为目标、经历／方向／行动／简历入口、待核对记录、下一步学习与交付、已完成行动成果。完成比例只统计实际行动，待确认草稿不当作经历；岗位关联仅使用行动原有的 job_id，简历入口不推断完成度。页面切换来源或账号时清空旧展示，拒绝旧请求回写。

本轮仅调整 uni-app 前端，复用已有接口，没有新增服务端接口或更改 Agent 工作流。角色短句在本地切换，对话草稿仍由用户确认发送。验证与手机尺寸预览见 [logs/frontend-refresh-20261101/README.md](logs/frontend-refresh-20261101/README.md)。

## 切页首帧与异常保护（2026-11-01）

- 四个 tab 页保留不依赖 Vue 初始数据的原生静态占位，实例 $nextTick／页面 ready 后直接显示正文；缓存页不重新盖占位。占位刻意写在页面原生模板内，不能改成依赖动态 props 才挂载的组件。
- 原生页面背景统一为纸面色；底栏按实际路由高亮，并由所有底栏实例共享导航锁。
- 成长资料与摘要在读取阶段共同校验、一次发布，异常响应显示重试入口并保留已加载正文；账号和来源的过期请求不能回写。
- 本轮微信模拟器连续 16 次切页未见页面缺失、占位不释放或运行异常；注入无效响应后错误入口仍可见，恢复真实请求后正常刷新。用户反馈的偶发持续白屏尚未稳定复现，不据此宣称排除了所有原因。

测试记录：`logs/page-switch-20261101/`。未修改后端或增加接口。

## 字体、卡片入场与交互点阵（2026-11-02）

界面统一使用 Qingsui Pixel UI，字体子集包含 GB2312 常用汉字、标点及源码文案，支持离线加载；罕见缺字回退系统字体。字体来源、许可及重新生成方式见 `assets/fonts/README.md`。

首页、任务、成长和我的每次显示时，卡片以 340ms 短距离上浮淡入，分组间隔最多 84ms。缓存返回也可播放，列表只动画前六项；页面与滚动容器保持原位，导航不等待动画。

四个主入口的轻背景由 `DotBackground.vue` 绘制。触摸时，点阵以落点为中心逐圈错开、轻微回弹并复位，波前的点略微变亮；卡片和文字保持原位。背景层不接收点击，原生与 H5 都使用本地 2D 画布，无逐帧 setData；静止时没有绘制循环，同时至多叠加两个波源，隐藏或卸载页面立即取消动画。H5 减少动态效果设置下保留静态底纹。

本次仅修改小程序前端。字体和入场记录见 `logs/surface-font-motion-20261102/`；将圆环反馈更正为点阵位移的记录见 `logs/dot-displacement-20261102/`。
