# 界面像素字体

原字体：Fusion Pixel 12px zh-Hans，作者 TakWolf，沿用项目 Web 端已有素材。

`fusion-pixel-12px-zh-hans.woff2` 是未修改的原始生成源，不参与运行时打包。`OFL.txt` 和 `upstream-licenses/` 保留原许可与上游字体许可。

运行 `python scripts/prepare-ui-font.py` 生成 GB2312 常用汉字、标点及源码文案字形的字体子集；派生字体更名为 **Qingsui Pixel UI**，保留字体内的原版权和许可记录。生成的 SCSS / WXSS 已包含字体数据，无需在线字体服务。

标题、正文、输入和底部导航统一使用这套字体，避免动态岗位名因缺少常用字而混用字形。代码与正式简历纸张使用各自的等宽或印刷字体，罕见缺字仍由系统字体回退。调整页面文案后重新运行生成脚本即可，普通前端构建不需要 Python 环境。
