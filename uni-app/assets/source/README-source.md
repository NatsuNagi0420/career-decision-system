# 穗奈微信小程序端原型素材包

本包包含 14 张由 GPT Image 2.5 生成的静态手机端原型图、32 枚独立透明像素图标，以及 8 张可单独复用的角色与插画透明 PNG。

## 页面原型

所有页面均为 9:16 竖版 PNG，尺寸 1440 × 2560 px。

1. 首页（已有少量资料）
2. 首次进入（空状态）
3. 对话页（自由聊聊）
4. 对话中的意图建议卡片
5. 经历记录后（待确认）
6. 我的画像
7. 岗位推荐列表
8. 岗位详情与能力对照
9. 成长路线
10. 七天行动详情
11. 简历版本与预览
12. 文件导出成功
13. 网络错误 / 发送失败
14. 空状态与加载状态（含无岗位、资料加载、服务不可用、文件上传失败）

建议参考的流程顺序：

**首页 → 对话 → 意图建议 / 经历记录 → 我的画像 → 岗位推荐 → 岗位详情与能力对照 → 成长路线 → 七天行动 → 简历预览 → 文件导出成功**

首次进入、网络错误与空/加载状态作为旁路状态参考。本包是静态图片原型，不包含页面跳转或真实小程序代码。

## 角色与插画

`角色与插画/` 下为 GPT Image 2.5 生成的独立透明 PNG：

- 穗奈全身立绘；
- 穗奈打招呼半身、思考半身；
- 像素猫咪伙伴；
- 像素桌面电脑场景；
- 像素盆栽与书本装饰；
- 成长路线旗帜插画；
- 经历资料道具组。

这些角色与插画都保留透明通道，可单独放入聊天区、空状态、成长卡片或素材库使用。

## 图标素材

`透明图标/` 下各 PNG 均保留真实透明通道，可单独用于界面排版。包含芽苗、首页、对话、岗位、成长图表、资料面板、导航箭头、更多、AI 灵感、文件、添加、语音、发送、搜索、目标、项目、确认、待确认警示、定位准星、位置、公司、新增项、状态标记、前进箭头、清单、行动开始、同步、连接状态、提醒、新增、编辑与关闭。

## 使用说明

- 所有示例姓名、公司、经历、目标和简历版本均为界面演示资料，不代表真实招聘信息或用户档案。
- 画像中的“已确认 / 暂时判断 / 待确认”用于展示信息可信度；未确认的项目内容不应直接写入正式简历。
- 岗位推荐不使用匹配百分比；成长行动需关联岗位能力缺口。
- 页面原型为静态视觉参考；正式开发时请以真实业务字段、来源和用户确认状态替换演示内容。
