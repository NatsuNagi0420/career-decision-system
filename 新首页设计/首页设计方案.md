# 职业规划平台 — 新首页设计方案

> 设计风格参考：Active Theory (activetheory.net) — 粒子动效与滚动体验  
> 设计系统：Clay Design System — 详见 `frontend/fr/DESIGN.md`（已复制到本目录）
> 基于项目现有 Clay 设计系统，支持浅色/深色双模式自动切换

---

## 一、设计目标

1. **展示技术力** — 通过全屏滚动 + 粒子动效，让首页本身成为"我们会做东西"的证据
2. **项目风格统一** — 完全复用现有 Clay 设计系统的 CSS 变量，首页看起来是项目的自然延伸
3. **双模式自适应** — 跟随系统主题自动切换浅色/深色模式
4. **轻量可维护** — 不引入 Three.js 等重型库，Canvas 粒子 + CSS 动画 + GSAP 即可

---

**重要：首页设计必须完全遵循 `/frontend/fr/DESIGN.md` 中定义的 Clay 设计系统，包括字体（Roobert）、色彩（暖白底 #faf9f7）、hover 动效（rotateZ(-8deg) + translateY(-80%) + 硬阴影）、间距体系和 border-radius 体系。**

## 四、技术实现方案

### 依赖

```bash
npm install gsap
```

只用 GSAP 做滚动动画控制，其余全部用 Vue 3 + Canvas + CSS 实现。

### 首页组件结构

```
frontend/fr/src/pages/Homepage.vue         ← 新首页，替换原来的
frontend/fr/src/components/homepage/
├── HeroSection.vue          # 首屏：Canvas粒子 + 标题 + 按钮
├── FeaturesSection.vue      # 三功能卡片
├── HighlightSection.vue     # 推理链亮点展示
├── StatsSection.vue         # 数据展示（数字增长动画）
├── FooterSection.vue        # CTA + 团队信息
└── ParticleCanvas.ts        # Canvas粒子系统逻辑（可复用）
```

### 关键技术点

| 功能 | 实现方式 |
|------|---------|
| 全屏滚动 | CSS `scroll-snap-type: y mandatory` |
| 粒子动效 | Canvas API（原生，200行以内） |
| 入场动画 | GSAP + IntersectionObserver |
| 数字增长 | GSAP 数字动画 |
| 推理链流程图 | CSS 动画箭头 + SVG |
| 主题切换 | 复用全局 `:root.dark` CSS 变量 |
| 响应式 | 媒体查询 + 移动端减少粒子数量 |

## 五、双模式（深色/浅色）切换

项目已有全局 CSS 变量系统（global.css），首页无需额外处理：

```vue
<!-- 使用项目现有的 CSS 变量即可 -->
<template>
  <div class="homepage"
    :style="{
      background: 'var(--clay-bg)',
      color: 'var(--clay-text)'
    }">
  </div>
</template>
```

主题切换由项目的暗黑模式控制器统一管理，首页被动响应即可。
